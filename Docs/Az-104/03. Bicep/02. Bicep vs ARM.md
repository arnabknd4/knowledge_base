# Azure Bicep vs ARM Templates

## 1. What is it?
- **ARM Templates**: JSON‑based Infrastructure‑as‑Code files consumed directly by Azure Resource Manager.  
- **Bicep**: A domain‑specific language (DSL) that compiles into ARM JSON, designed to simplify authoring and maintenance.

---

## 2. Why do we need it?
- **ARM**: Universal compatibility, legacy support, and direct debugging.  
- **Bicep**: Readable, modular, type‑safe, and easier to maintain for enterprise deployments.

---

## 3. Core Exam Focus
- **AZ‑104 Exam**: You may encounter both formats.  
  - ARM: Identify parameters, variables, resources, outputs.  
  - Bicep: Author/modify files, deploy via CLI, understand modules and scopes.  
- **Key Command**:  
  - ARM: `az deployment group create --template-file template.json`  
  - Bicep: `az deployment group create --template-file main.bicep`

---

## 4. Real‑World Use Case
- **ARM**: Exported templates from portal for compliance audits.  
- **Bicep**: Modular deployments (e.g., AKS + Key Vault + RBAC) across multiple regions with parameterized values.

---

## 5. Interview Lens
- **Q1:** Why prefer Bicep over ARM JSON?  
  *Bicep is concise, modular, and easier to maintain; ARM is verbose but universally supported.*  
- **Q2:** How do you secure secrets in Bicep?  
  *Use Key Vault references and RBAC restrictions.*  
- **Q3:** What’s the deployment engine difference?  
  *None — both compile to ARM JSON consumed by Azure Resource Manager.*

---

## 6. Common Mistakes
- Misconfiguring **scope** (RG vs subscription).  
- Overlooking **dependencies** (`dependsOn`).  
- Assuming Bicep replaces ARM — in reality, Bicep compiles to ARM JSON.

---

## 7. Mental Model
Think of **ARM JSON** as the “machine language” of Azure deployments, and **Bicep** as the “high‑level programming language” that compiles down to it.

---

## 8. Revision Summary
- ARM = raw JSON engine; Bicep = modern DSL compiled into ARM.  
- Exam covers **interpret, modify, deploy, convert** templates.  
- **Bicep preferred for authoring**, ARM for legacy/debugging.  
- Both produce identical ARM JSON payloads.  
- Watch for **scope traps** and **incremental vs complete mode**.
