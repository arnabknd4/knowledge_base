# Deploy Azure Infrastructure Using JSON ARM Templates

## 1. What is it?
Azure Resource Manager (ARM) templates are JSON files that declaratively define Azure resources and their configurations.

## 2. Why do we need it?
- Enables **infrastructure as code (IaC)** for repeatable, consistent deployments.  
- Supports **governance, automation, and scalability** across environments.  
- Integrates with CI/CD pipelines for DevOps workflows.  

## 3. Core Exam Focus
- Structure of ARM templates: `parameters`, `variables`, `resources`, `outputs`.  
- Deploy via **Portal, CLI, PowerShell, REST API**.  
- Use **parameter files** for environment-specific values.  
- Common traps: missing dependencies, incorrect resource names, wrong location settings.  

## 4. Real‑World Use Case
Architects deploy multi‑region VNets, VM scale sets, and monitoring agents using ARM templates integrated into Azure DevOps pipelines.

## 5. Interview Lens
- How do ARM templates differ from Terraform/Bicep?  
- How would you enforce governance using ARM templates?  
- What’s the trade‑off between imperative vs declarative deployments?  

## 6. Common Mistakes
- Hardcoding values instead of using parameters.  
- Forgetting resource dependencies (`dependsOn`).  
- Misusing resource naming conventions → collisions.  
- Ignoring template validation before deployment.  

## 7. Mental Model
Think of ARM templates as a **blueprint JSON file** — once defined, Azure Resource Manager ensures the “building” (infrastructure) matches the blueprint exactly.

## 8. Supporting Code Snippets

**Basic ARM Template Structure:**
```json
{
  "$schema": "https://schema.management.azure.com/schemas/2019-04-01/deploymentTemplate.json#",
  "contentVersion": "1.0.0.0",
  "parameters": {
    "storageName": {
      "type": "string"
    }
  },
  "resources": [
    {
      "type": "Microsoft.Storage/storageAccounts",
      "apiVersion": "2022-09-01",
      "name": "[parameters('storageName')]",
      "location": "[resourceGroup().location]",
      "sku": {
        "name": "Standard_LRS"
      },
      "kind": "StorageV2",
      "properties": {}
    }
  ]
}
```
Deploy Template via CLI:
``` sh
az deployment group create \
  --resource-group MyRG \
  --template-file azuredeploy.json \
  --parameters @azuredeploy.parameters.json
```
Deploy Template via PowerShell:
```ps1
New-AzResourceGroupDeployment `
  -ResourceGroupName MyRG `
  -TemplateFile azuredeploy.json `
  -TemplateParameterFile azuredeploy.parameters.json
```
