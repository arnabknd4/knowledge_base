# How Microsoft Entra ID Works as a Directory for Cloud Apps

## 1. Identity Provider Role
- Microsoft Entra ID acts as the **cloud directory** for users, groups, and devices.  
- It provides **authentication** (who you are) and **authorization** (what you can access).  
- Cloud apps integrate with Entra ID to leverage **Single Sign‑On (SSO)** and **Multi‑Factor Authentication (MFA)**.

---

## 2. Application Integration
- **SaaS Apps**: Thousands of apps (Salesforce, ServiceNow, Zoom, etc.) can be connected via SAML, OAuth2, or OpenID Connect.  
- **Custom Apps**: Developers register applications in Entra ID to obtain client IDs/secrets and configure redirect URIs.  
- **Microsoft Services**: Office 365, Teams, SharePoint, and Azure services natively rely on Entra ID.

---

## 3. Directory Functions
- **User & Group Management**: Centralized directory for employees, contractors, and external partners.  
- **App Registration**: Each cloud app is registered in Entra ID with permissions and consent flows.  
- **Conditional Access**: Policies enforce rules (e.g., require MFA if logging in from outside corporate network).  
- **Managed Identities**: Azure resources (VMs, Functions, AKS) can authenticate without storing credentials.

---

## 4. Real‑World Example
- A company integrates Salesforce with Entra ID.  
- Employees log in using their Microsoft 365 credentials.  
- Entra ID enforces MFA and Conditional Access (e.g., block login from risky IPs).  
- RBAC ensures only sales staff can access Salesforce data.

---

## 5. Benefits
- **Centralized Identity**: One directory for all cloud apps.  
- **Security**: MFA, passwordless, risk‑based conditional access.  
- **Productivity**: Seamless SSO reduces password fatigue.  
- **Governance**: Privileged Identity Management (PIM) and audit logs ensure compliance.

---

## ✅ Quick Flashcard Recap
- Entra ID = cloud directory for apps.  
- Provides SSO, MFA, RBAC, Conditional Access.  
- Integrates with SaaS, custom, and Microsoft apps.  
- Managed identities secure Azure resources.  
- Centralized governance and compliance.
