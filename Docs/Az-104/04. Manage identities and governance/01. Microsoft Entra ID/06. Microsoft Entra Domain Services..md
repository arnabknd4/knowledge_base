# Microsoft Entra Domain Services (formerly Azure AD Domain Services)

## 1. What It Is
Microsoft Entra Domain Services (EDS) is a **managed domain service** in Azure.  
It provides traditional Active Directory features like:
- Domain join
- Group Policy
- LDAP
- Kerberos/NTLM authentication  

All without deploying or managing domain controllers yourself.

---

## 2. Why It Matters
- **Legacy App Support**: Lift‑and‑shift apps that require AD DS protocols into Azure.  
- **No Domain Controllers**: Microsoft manages patching, replication, and availability.  
- **Hybrid Identity**: Works with Entra ID as the authoritative identity source.  
- **Cloud‑Only Option**: Useful if you don’t have on‑prem AD but still need AD DS features.

---

## 3. Key Features
- **Domain Join**: Azure VMs can join the managed domain.  
- **Group Policy**: Apply GPOs to manage VM configurations.  
- **Authentication**: Kerberos and NTLM for legacy workloads.  
- **High Availability**: Microsoft provides multiple domain controllers.  
- **Integration**: Syncs with Entra ID users, groups, and credentials.

---

## 4. Comparison – Entra Domain Services vs AD DS

| Feature                  | Entra Domain Services | AD DS (On‑Prem) |
|---------------------------|-----------------------|----------------|
| Domain Controllers        | Managed by Microsoft | Self‑managed   |
| Authentication Protocols  | Kerberos, NTLM, LDAP | Kerberos, NTLM, LDAP |
| Group Policy              | Supported            | Supported      |
| Integration               | With Entra ID        | With on‑prem AD |
| Maintenance               | No patching required | Requires patching, backups |
| Use Case                  | Legacy apps in cloud | On‑prem workloads |

---

## 5. Limitations
- **No Forest Trusts**: Unlike full AD DS, trust relationships are restricted.  
- **Limited Customization**: You don’t control domain controllers directly.  
- **Cost**: Charged per hour based on SKU.  
- **Scope**: Best for legacy workloads; modern apps should use Entra ID directly.

---

## 6. Real‑World Scenario
A company migrates a legacy HR application that requires LDAP authentication.  
- They enable Entra Domain Services in Azure.  
- The app authenticates against the managed domain using Kerberos.  
- Users are synced from Entra ID, so HR staff log in with their Microsoft 365 credentials.  
- No need to maintain on‑prem domain controllers.
