# Microsoft Entra ID Licensing – P1 vs P2

## 1. Base Tier (Free)
- User & group management.  
- Device registration.  
- Basic security reports.  
- Single sign‑on (SSO) for Microsoft services and limited SaaS apps.  

---

## 2. Premium P1
Designed for **enterprise identity management**:
- **Conditional Access**: Enforce MFA, location‑based rules, device compliance.  
- **Hybrid Identity**: Azure AD Connect, seamless SSO with on‑prem AD.  
- **Dynamic Groups**: Auto‑membership based on rules.  
- **Self‑Service Features**: Password reset, group management.  
- **Advanced Security Reports**: Risk detection, monitoring.  
- **Licensing Fit**: Best for organizations needing **scalable identity governance** and hybrid integration.

---

## 3. Premium P2
Adds **advanced security and governance**:
- **Identity Protection**: Risk‑based conditional access (detect risky sign‑ins, compromised accounts).  
- **Privileged Identity Management (PIM)**: Just‑in‑time admin access, approval workflows, audit trails.  
- **Access Reviews**: Periodic checks to ensure users still need access.  
- **Advanced Compliance**: Stronger governance for regulated industries.  
- **Licensing Fit**: Best for enterprises with **strict compliance/security requirements** (finance, healthcare, government).

---

## ✅ Quick Flashcard Recap
- **Free** → Basic IAM, SSO.  
- **P1** → Conditional Access, hybrid identity, dynamic groups, self‑service.  
- **P2** → Adds Identity Protection, PIM, Access Reviews.  
- **Architect Lens**:  
  - P1 = scalable enterprise identity.  
  - P2 = advanced governance + compliance.
