# When Should You Use Azure Cloud Shell?

## 1. What is it?
A browser-based shell (Bash/PowerShell) hosted in Azure with preinstalled tools like `az CLI`, Terraform, Git, and `kubectl`.

## 2. When to Use
- **Quick Admin Tasks** → Run `az` commands without installing CLI locally.  
- **Multi‑Subscription Management** → Manage resources across tenants with your Azure AD identity.  
- **Learning/Exam Prep** → Practice CLI/PowerShell commands in a safe, sandboxed environment.  
- **Troubleshooting** → Execute scripts instantly without worrying about local dependencies.  
- **Automation Kickstart** → Test Terraform/ARM/Bicep templates before integrating into pipelines.  
- **Cross‑Platform Access** → Same environment from portal, mobile app, or VS Code extension.  

## 3. Supporting Code Snippets
**Check current subscription:**
```bash
az account show --output table
```
Switch between Bash and PowerShell:
``` sh
# Bash → PowerShell
clouddrive:\> pwsh
```
Run a Terraform init inside Cloud Shell:
```sh
cd ~/clouddrive/terraform
terraform init
```
Deploy a resource group via CLI:
```sh
az group create --name MyRG --location eastus
```
## 4. Real‑World Use Case
Architects use Cloud Shell to enforce governance scripts (tagging, policy assignments) across 200+ subscriptions without installing tools locally.

## 5. Interview Lens
- Why use Cloud Shell instead of local CLI?
- How do you persist scripts across sessions?
- What’s the trade‑off between Cloud Shell and DevOps pipelines?

## 6. Common Mistakes
- Forgetting persistent storage setup → scripts lost.
- Assuming Cloud Shell replaces CI/CD (it doesn’t).
- Confusing RBAC (access control) with Policy (governance).

## 7. Mental Model
Think of Cloud Shell as a “portable toolbox in the cloud” — always available, preloaded, tied to your Azure AD identity.

## 8. Revision Summary
- Use for quick tasks, troubleshooting, and learning.
- Persistent storage via clouddrive (5 GB).
- Preinstalled tools: az CLI, Terraform, Git, kubectl.
- Access via portal, `shell.azure.com`, `VS Code`, mobile app.
- Exam trap: Cloud Shell ≠ full automation platform.
