# 📜 Azure Backup and Compliance

## 1. Regulatory Retention
- Azure Backup supports **long‑term data retention** (months → years).  
- **Archive tier** provides cost‑effective storage for compliance (e.g., 7‑year financial record retention).  
- Meets industry requirements for **finance, healthcare, and government workloads**.  

## 2. Security Controls
- **Encryption**: Data encrypted in transit (HTTPS) and at rest (AES‑256).  
- **Soft Delete**: Protects against accidental/malicious deletion (14‑day retention after delete).  
- **RBAC + MFA**: Ensures only authorized users can configure or restore backups.  

## 3. Governance & Monitoring
- **Recovery Services vault**: Centralized policy enforcement for retention and redundancy.  
- **Backup Center**: Enterprise‑scale monitoring, compliance checks, and audit logs.  
- Integration with **Azure Monitor** and **Security Center** for alerts and anomaly detection.  

## 4. Compliance Certifications
- Azure Backup inherits Azure’s compliance framework (ISO, HIPAA, GDPR, SOC, etc.).  
- Ensures workloads meet **global and regional regulatory standards**.  

---

# 🧠 Mental Model
Think of Azure Backup as a **“compliance safety net”**:  
- Retention policies = regulatory timelines.  
- Encryption + RBAC = secure access.  
- Vault + Backup Center = governance and audit trail.
