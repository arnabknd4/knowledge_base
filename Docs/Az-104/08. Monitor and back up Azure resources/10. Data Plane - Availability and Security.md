# 🔐 Data Plane – Availability and Security (Azure Backup)

## 1. Availability
- **Redundancy Options**:  
  - **Locally Redundant Storage (LRS)** → 3 copies within a single datacenter.  
  - **Geo‑Redundant Storage (GRS)** → replicated to a secondary region for disaster recovery.  
- **High Availability**: Recovery Services vault ensures backup data is always accessible.  
- **Multiple Restore Points**: Policies allow multiple backups per day, ensuring recent recovery options.  
- **Resilience**: Snapshots + vault storage provide layered availability (short‑term + long‑term).  

## 2. Security
- **Encryption**:  
  - Data encrypted in transit (HTTPS).  
  - Data encrypted at rest (AES‑256).  
- **Soft Delete**: Protects against accidental or malicious deletion by retaining data for 14 days after deletion.  
- **Role‑Based Access Control (RBAC)**: Ensures only authorized users can configure or restore backups.  
- **Multi‑Factor Authentication (MFA)**: Adds an extra layer of protection for backup operations.  
- **Monitoring & Alerts**: Integration with Azure Monitor and Security Center for anomaly detection.  

---

# 🧠 Mental Model
Think of the Data Plane as a **“secure vault with multiple locks and backup copies”** — availability ensures the vault is always accessible, while security ensures only the right people can open it.

---

# 📌 Revision Summary
- Availability → LRS/GRS redundancy, multiple restore points  
- Security → encryption (in transit + at rest), RBAC, MFA  
- Soft delete protects against accidental/malicious deletion  
- Monitoring + alerts strengthen defense  
- Data Plane = balance of resilience + protection
