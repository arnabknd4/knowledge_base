# Metrics Explorer

## 1. What is it?
An Azure Monitor tool that lets you **visualize, analyze, and correlate metrics** across Azure resources in real time.

## 2. Why do we need it?
Provides deep visibility into resource performance, helps troubleshoot anomalies, and supports governance/compliance dashboards.

## 3. Core Exam Focus
- Scope selection (subscription, resource group, resource)
- Time range & granularity (avg, min, max, sum)
- Dimension filters (instance, region, etc.)
- Multiple charts for correlation
- Common trap: forgetting to enable diagnostic settings → missing guest/application metrics

## 4. Real‑World Use Case
A global enterprise uses Metrics Explorer to:
- Monitor CPU/memory across VM clusters
- Detect network bottlenecks during peak traffic
- Correlate disk latency spikes with application errors
- Trigger alerts routed to ITSM tools for automated incident response

## 5. Interview Lens
- Q: How do you troubleshoot VM performance using Metrics Explorer?
  - A: Plot CPU, memory, and disk metrics; correlate spikes with workload logs; set alerts for thresholds.
- Q: Why use Metrics Explorer over basic metrics?
  - A: Explorer allows correlation, filtering, and advanced queries (PromQL/KQL).
- Q: How do you secure access?
  - A: Assign Monitoring Reader role for cross‑resource visibility.

## 6. Common Mistakes
- Ignoring granularity → misleading averages
- Over‑collecting metrics → unnecessary cost
- Not assigning RBAC → limited visibility
- Assuming host metrics alone explain performance issues

## 7. Mental Model
Think of Metrics Explorer as a **fitness tracker dashboard**:
- Each metric = a vital sign (CPU = heart rate, memory = stamina)
- Charts = daily activity graphs
- Alerts = warnings when vitals cross thresholds

## 8. Revision Summary
- Metrics Explorer = charting & analyzing tool in Azure Monitor
- Supports platform + custom metrics
- Features: scope, time range, aggregation, filters, multiple charts
- PromQL/KQL for advanced queries
- Requires Monitoring Reader role for cross‑resource views
- Use for troubleshooting, alerting, compliance dashboards
