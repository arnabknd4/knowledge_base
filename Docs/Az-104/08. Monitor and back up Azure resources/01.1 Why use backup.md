# 🌟 Why Use Azure Backup?

## 1. Data Protection
- Provides **restore points** for VMs, files, folders, and databases.  
- Protects against accidental deletion, corruption, or ransomware attacks.  

## 2. Compliance & Retention
- Supports **long‑term retention** via Archive tier.  
- Meets regulatory requirements (finance, healthcare, government).  

## 3. Cost Optimization
- **Differential backups** reduce storage usage.  
- **Selective disk backup** avoids unnecessary costs.  
- Archive tier ensures low‑cost storage for rarely accessed data.  

## 4. Hybrid & On‑Premises Support
- Extends protection to **on‑prem workloads** via MABS/DPM.  
- Provides centralized management across hybrid environments.  

## 5. Security & Resilience
- **Encryption** (in transit + at rest).  
- **Soft delete** prevents accidental/malicious deletion.  
- **RBAC + MFA** ensure secure administration.  

## 6. Simplified Monitoring & Administration
- **Recovery Services vault** → local management.  
- **Backup Center** → enterprise‑scale monitoring, compliance, and cost insights.  
- Integrated with **Azure Monitor** for alerts and reporting.  

---

# 🧠 Mental Model
Think of Azure Backup as a **“time machine vault”**:  
- It lets you rewind workloads to safe checkpoints.  
- It ensures compliance, cost efficiency, and resilience.  
- It simplifies monitoring and governance at scale.

# 🔐 Azure Backup – Security Features

## 1. Azure Role‑Based Access Control (RBAC)
- Ensures only **authorized users** can configure, manage, or restore backups.  
- Supports **least privilege access** by assigning roles at subscription, resource group, or vault level.  
- Example roles: Backup Contributor, Backup Operator, Reader.  

## 2. Encryption of Backups
- **In transit**: Data encrypted using HTTPS.  
- **At rest**: AES‑256 encryption in Recovery Services vault.  
- Option to use **customer‑managed keys (CMK)** for compliance.  

## 3. No Internet Connectivity Required
- Backup traffic flows through the **Azure backbone network**, not the public internet.  
- Reduces exposure to external threats.  
- Ensures secure communication between workloads and Recovery Services vault.  

## 4. Soft Delete
- Protects against accidental or malicious deletion.  
- Retains backup data for **14 days after deletion**.  
- Allows recovery even if a backup item is deleted.
