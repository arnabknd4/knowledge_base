# 💰 Azure Backup Pricing & Reserved Capacity

## 1. Backup Pricing Components
- **Protected Instance Cost**  
  - ≤ 50 GB → $5/month  
  - 50–500 GB → $10/month  
  - > 500 GB → $10 per 500 GB increment  
  - Example: 1.2 TB VM = $30/month + storage  

- **Storage Cost (Pay‑As‑You‑Go)**  
  - **LRS** → ~$0.0224/GB  
  - **ZRS** → ~$0.028/GB  
  - **GRS** → ~$0.0448/GB  
  - **RA‑GRS** → ~$0.0569/GB  
  - **Archive Tier** → ~$0.0027–0.0054/GB (lowest cost, but 180‑day minimum retention)  

---

## 2. Azure Backup Storage Reserved Capacity
- **Commitment**: 1‑year or 3‑year reservations.  
- **Blocks**: Available in **100 TB** or **1 PB** increments.  
- **Scope**: Applies to **Standard tier storage** (LRS, ZRS, GRS, RA‑GRS).  
- **Payment**: Upfront or monthly installments.  
- **Discounts**: Up to ~40–50% compared to pay‑as‑you‑go.  
- **Limitation**: Archive tier not eligible for reserved capacity.

## 4. Architect’s Lens
- **Pay‑As‑You‑Go** → Best for dev/test or unpredictable workloads.  
- **Reserved Capacity** → Best for predictable, long‑term compliance workloads (finance, healthcare, SAP HANA).  
- **Archive Tier** → Ultra‑low cost for rarely accessed backups, but beware of early deletion fees.  

---

# 📌 Revision Summary
- Pricing = **instance cost + storage cost**.  
- Reserved capacity = **discounted commitment** (100 TB/1 PB, 1‑yr/3‑yr).  
- Archive tier = **lowest cost**, but not eligible for reserved capacity.
