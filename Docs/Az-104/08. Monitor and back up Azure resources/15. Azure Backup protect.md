# 🗄️ Azure Backup for Azure VMs Hosting SQL Server

## ✅ Supported Scenario
Yes — **Azure Backup can protect Azure VMs that host SQL Server instances**.  
It does this by combining **VM‑level backup** with **workload‑aware backup extensions**.

---

## 1. VM‑Level Backup
- Captures **OS + data disks** of the VM.  
- Provides **crash‑consistent** or **app‑consistent** snapshots using VSS (Windows).  
- Ensures the entire VM can be restored if corrupted or deleted.  

## 2. Workload‑Aware Backup (SQL Extension)
- Azure Backup installs a **SQL Server backup extension** inside the VM.  
- Enables **transaction‑consistent backups** by capturing database + transaction logs.  
- Supports **point‑in‑time restore (PITR)** for SQL workloads.  
- Provides **granular recovery**: restore individual databases instead of the whole VM.  

## 3. Benefits
- **Unified Management**: Both VM and SQL backups managed via Recovery Services vault.  
- **Multiple Recovery Points**: Daily/hourly backups with retention policies.  
- **Compliance**: Archive tier for long‑term retention of SQL backups.  
- **Security**: Encryption, RBAC, soft delete protect SQL data.  

---

# 🧠 Mental Model
Think of Azure Backup as a **“dual shield”**:  
- VM backup = protects the infrastructure.  
- SQL extension = protects the workload data with transaction‑level precision.
