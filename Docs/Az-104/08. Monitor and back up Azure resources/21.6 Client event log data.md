# Client Event Log Data

## 1. What is it?
Telemetry collected from the **guest OS and workloads** inside a VM, capturing system events, application logs, and security signals for analysis.

## 2. Why do we need it?
Provides visibility into **user activity, workload health, and security posture**. Essential for troubleshooting, compliance audits, and detecting anomalies beyond host metrics.

## 3. Core Exam Focus
- **Azure Monitor Logs** → Centralized query/analysis with KQL
- **Azure Storage** → Long‑term archival of event logs (cost‑effective)
- **Azure Event Hubs** → Real‑time streaming to SIEM/third‑party tools
- Common trap: not configuring diagnostic settings → logs expire after 90 days

## 4. Real‑World Use Case
A financial enterprise routes client event logs to:
- **Azure Monitor Logs** for operational dashboards
- **Azure Storage** for 7‑year retention (regulatory compliance)
- **Azure Event Hubs** to forward logs into Splunk for fraud detection

## 5. Interview Lens
- Q: Why use Event Hubs instead of Storage?
  - A: Event Hubs supports real‑time ingestion into SIEM; Storage is archival.
- Q: How do you balance cost vs compliance?
  - A: Use Storage for long‑term retention, Monitor Logs for short‑term analytics.
- Q: What happens if logs aren’t routed?
  - A: You lose audit visibility, impacting compliance and incident response.

## 6. Common Mistakes
- Assuming logs are retained by default (they expire after 90 days)
- Not setting retention policies in Storage
- Overloading Monitor Logs with unnecessary data → cost spikes
- Forgetting to secure Storage/Event Hub with RBAC

## 7. Mental Model
Think of client event logs like **CCTV footage**:
- Monitor Logs = live control room
- Storage = archive vault
- Event Hubs = streaming feed to external security teams

## 8. Revision Summary
- Client event logs = guest OS + workload telemetry
- Route to Monitor Logs for analysis
- Route to Storage for compliance retention
- Route to Event Hubs for SIEM integration
- Default retention = 90 days unless configured
- Secure endpoints with RBAC/Policy
