# Azure Backup – Key Features

## 1. Zero‑Infrastructure Backup Solution
- No need to deploy or maintain backup servers or appliances.  
- Backups are managed entirely through **Recovery Services vaults** in Azure.  
- Supports VMs, files, folders, SQL databases, and on‑premises workloads.  

## 2. At‑Scale Management
- Centralized management of backups across subscriptions and regions.  
- Policy‑based automation for scheduling, retention, and compliance.  
- Integration with **Azure Policy** for governance at enterprise scale.  
- Monitoring and reporting via **Azure Monitor** and Log Analytics.  

## 3. Security
- Data encrypted at rest and in transit (AES‑256 + HTTPS).  
- **Soft delete** protects against accidental or malicious deletion.  
- Role‑Based Access Control (RBAC) ensures only authorized users manage backups.  
- Multi‑factor authentication and alerts for suspicious activity.  

---

## 🧠 Mental Model
Think of Azure Backup as a **“cloud vault with automated guards”** — it stores snapshots securely, scales across workloads, and protects against accidental or malicious loss.
