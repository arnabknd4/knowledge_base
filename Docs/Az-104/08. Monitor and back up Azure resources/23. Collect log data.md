# Collect Log Data (Azure VM Monitoring)

## 1. What is it?
The process of capturing **diagnostic and activity logs** from Azure VMs to analyze performance, detect issues, and meet compliance requirements.

## 2. Why do we need it?
- Provides visibility into VM operations and guest OS events.
- Supports troubleshooting, governance, and security auditing.
- Enables integration with monitoring tools and SIEM systems.

## 3. Core Exam Focus
- Configure **Diagnostic Settings** to route logs.
- Destinations:
  - **Azure Monitor Logs** → centralized analysis with KQL.
  - **Azure Storage** → long‑term archival, cost‑effective.
  - **Azure Event Hubs** → real‑time streaming to external tools.
- Common trap: logs expire after 90 days if not routed.

## 4. Real‑World Use Case
A financial services firm:
- Sends VM diagnostic logs to **Azure Monitor Logs** for dashboards.
- Archives logs in **Azure Storage** for 7‑year compliance.
- Streams logs via **Event Hubs** into Splunk for fraud detection.

## 5. Interview Lens
- Q: Why use Event Hubs instead of Storage?
  - A: Event Hubs supports real‑time ingestion into SIEM; Storage is archival.
- Q: How do you balance cost vs compliance?
  - A: Use Storage for long‑term retention, Monitor Logs for short‑term analytics.
- Q: What happens if logs aren’t routed?
  - A: You lose audit visibility, impacting compliance and incident response.

## 6. Common Mistakes
- Assuming logs are retained by default (they expire after 90 days).
- Not setting retention policies in Storage.
- Overloading Monitor Logs with unnecessary data → cost spikes.
- Forgetting to secure Storage/Event Hub with RBAC.

## 7. Mental Model
Think of log routing like **security camera footage**:
- Monitor Logs = live control room.
- Storage = archive vault.
- Event Hubs = streaming feed to external security teams.

## 8. Revision Summary
- Collect logs via Diagnostic Settings.
- Route to Monitor Logs (analysis), Storage (retention), Event Hubs (streaming).
- Default retention = 90 days unless configured.
- Secure endpoints with RBAC/Policy.
- Balance cost vs compliance with tiered routing.
