# 📌 Support Matrix – Azure VM Backups

## 1. Backup Scenarios
| Scenario | Agent Requirement | OS Support | Restore Options |
| --- | --- | --- | --- |
| **Azure VM Backup (default)** | Azure VM Backup Extension (auto‑installed) | Windows & Linux | Full VM, Disk, File/Folder |
| **File/Folder Backup (Windows only)** | MARS Agent | Windows | File/Folder restore |
| **MABS/DPM Integration** | MABS/DPM Agent | Windows & Linux workloads | Files, Volumes, System State, Bare Metal, App Data |

---

## 2. Restore Methods
| Restore Type | Scope | Best Use Case |
| --- | --- | --- |
| **Full VM Restore** | Entire VM (OS + disks) | VM corruption, accidental deletion |
| **Disk Restore** | Individual disks | Targeted disk recovery |
| **Replace Disk** | Swap restored disk with existing | Disk corruption without full VM rollback |
| **File/Folder Restore** | Granular files/folders | Accidental file deletion |
| **Cross‑Region Restore (CRR)** | Paired region restore | Regional outage, DR |
| **App‑Aware Restore** | SQL, SAP HANA workloads | Transaction‑consistent PITR |

---

## 3. OS Support
- **Windows VMs**  
  - App‑consistent backups via **VSS**.  
  - File/Folder restore supported.  
- **Linux VMs**  
  - Crash‑consistent backups supported.  
  - App‑consistent backups via **pre/post scripts** (databases).  

---

## 4. Backup Frequency & Retention
- **Default** → Daily backups.  
- **Retention** → Configurable (daily, weekly, monthly, yearly).  
- **Archive Tier** → Long‑term retention at lowest cost.  

---

## 5. Security & Management
- **Encryption** → HTTPS in transit, AES‑256 at rest.  
- **RBAC** → Role‑based access control for backup/restore.  
- **Soft Delete** → 14‑day recovery window after deletion.  
- **No Internet Required** → Backup traffic flows via Azure backbone.  

---

# 🧠 Mental Model
Azure VM backup support matrix = **“layers of protection”**:
- VM extension → whole VM snapshots.  
- MARS agent → file/folder granularity.  
- MABS/DPM → enterprise workloads.  
- Restore methods → full VM, disk, file, cross‑region, app‑aware.  

---

# 📌 Exam‑Style Revision Summary
- **Backup types**: VM‑level, file/folder (Windows), MABS/DPM.  
- **Restore types**: Full VM, Disk, File/Folder, CRR, App‑aware.  
- **OS support**: Windows (VSS), Linux (scripts).  
- **Retention**: Daily → Archive tier.  
- **Security**: RBAC, encryption, soft delete.
