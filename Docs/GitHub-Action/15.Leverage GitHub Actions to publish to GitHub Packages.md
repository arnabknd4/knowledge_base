# Leverage GitHub Actions to Publish to GitHub Packages

## 1. GitHub Packages
- GitHub Packages is a **package hosting service** integrated with GitHub.
- Supports multiple ecosystems (npm, Maven, NuGet, RubyGems, Docker).
- Provides **versioned storage** and **distribution** of packages alongside source code.

## 2. Standard Package Manager
- GitHub Packages works seamlessly with standard package managers:
  - **npm** for JavaScript.
  - **Maven/Gradle** for Java.
  - **NuGet** for .NET.
  - **RubyGems** for Ruby.
  - **Docker CLI** for containers.
- Authentication is handled via **GITHUB_TOKEN** or PAT (Personal Access Token).

## 3. GitHub Packages as a Container Registry
- GitHub Packages can act as a **container registry** for Docker images.
- Supports OCI-compliant images.
- Example workflow:
```yaml
  - name: Log in to GitHub Container Registry
    run: echo ${{ secrets.GITHUB_TOKEN }} | docker login ghcr.io -u ${{ github.actor }} --password-stdin
  - name: Build and push Docker image
    run: |
      docker build . -t ghcr.io/<OWNER>/<IMAGE_NAME>:<TAG>
      docker push ghcr.io/<OWNER>/<IMAGE_NAME>:<TAG>
```

## 4. GitHub Packages vs GitHub Releases
- GitHub Packages:
  - Stores build artifacts (libraries, images, modules).
  - Integrated with package managers.
  - Used for dependency management in CI/CD.

- GitHub Releases:
    - Stores compiled binaries or release notes.
    - Intended for end-user distribution.
    - Used for versioned software releases, not dependency resolution.

## 5. Build and Publish Packages from GitHub
Typical workflow steps:
- Checkout code using actions/checkout.
- Authenticate with GitHub Packages using GITHUB_TOKEN.
- Build package with the appropriate package manager.
- Publish package to GitHub Packages registry.

Example (npm):
```yaml
jobs:
  publish:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Setup Node.js
        uses: actions/setup-node@v3
        with:
          node-version: '16'
          registry-url: 'https://npm.pkg.github.com'
      - run: npm install
      - run: npm publish
        env:
          NODE_AUTH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

## 7. Interview Questions and Answers
Q: What is GitHub Packages?
A: A package hosting service integrated with GitHub for multiple ecosystems.

Q: How do you authenticate to publish packages?
A: Using GITHUB_TOKEN or a PAT in workflow steps.

Q: Difference between GitHub Packages and GitHub Releases?
A: Packages are for dependency management; Releases are for distributing compiled binaries to end users.

## 8. Revision Summary
- GitHub Packages = package hosting service.
- Works with standard package managers (npm, Maven, NuGet, RubyGems, Docker).
- Can act as a container registry (ghcr.io).
- Packages ≠ Releases (dependency vs distribution).
- Build → Authenticate → Publish via GitHub Actions.

``` yaml
name: Node.js Package

on:
  release:
    types: [created]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 12
      - run: npm ci
      - run: npm test

  publish-gpr:
    needs: build
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 12
          registry-url: https://npm.pkg.github.com/
      - run: npm ci
      - run: npm publish
        env:
          NODE_AUTH_TOKEN: ${{secrets.GITHUB_TOKEN}}
```
