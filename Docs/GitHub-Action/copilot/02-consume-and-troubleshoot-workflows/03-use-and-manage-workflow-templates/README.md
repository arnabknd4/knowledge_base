# Use and manage workflow templates

Choose the reuse mechanism that matches the desired lifecycle: copied scaffold, centrally invoked workflow, or step-level action. Account for organization visibility and discoverability, then distinguish reversible disabling from removal.

## Objectives

- [Consume organization-level and reusable workflows](./01-organization-and-reusable-workflows/study-guide.md)
- [Consume non-public organization workflow templates](./02-non-public-organization-templates/study-guide.md)
- [Use public and private/non-public starter workflows](./03-public-and-private-starter-workflows/study-guide.md)
- [Distinguish starter workflows, reusable workflows, and composite actions](./04-distinguish-reuse-mechanisms/study-guide.md)
- [Contrast disabling and deleting workflows](./05-disable-versus-delete/study-guide.md)

Suggested order: understand centralized reuse → find non-public sources → apply starter templates → compare mechanisms → operate workflow lifecycle.
