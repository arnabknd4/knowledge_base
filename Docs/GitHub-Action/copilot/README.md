# GH-200 Architect Study Track

This study track organizes architect-level preparation for the GitHub Actions certification (GH-200). The domain and objective structure follows the official study guide; the explanations add operational and architecture context to support understanding rather than memorization.

## Domains

1. [Author and manage workflows](./01-author-and-manage-workflows/README.md) — design workflow triggers, structure, data flow, and execution.
2. [Consume and troubleshoot workflows](./02-consume-and-troubleshoot-workflows/README.md) — interpret runs, artifacts, matrices, and workflow templates.
3. [Author and maintain actions](./03-author-and-maintain-actions/README.md) — create, package, version, publish, and support custom actions.
4. [Manage GitHub Actions for the enterprise](./04-manage-github-actions-for-the-enterprise/README.md) — govern reusable automation, runners, secrets, and variables at scale.
5. [Secure and optimize automation](./05-secure-and-optimize-automation/README.md) — apply identity, supply-chain, execution-safety, performance, and cost controls.

## Recommended learning path

1. Study the official [GH-200 syllabus](../copilot-github-syllabus.md) and note each domain's weight.
2. Work through domains in order, building and modifying examples in a non-production repository.
3. For each objective, explain the design choice, alternatives, failure modes, security boundaries, and operating cost without relying on notes.
4. Practice integrated scenarios that combine workflow design, governance, troubleshooting, and security.
5. Revisit the current official study guide before booking: exam objectives and product behavior can change.

## How to use each objective guide

Each domain contains topic folders, then one folder per exam objective, with a `study-guide.md` in each objective folder. Use the guides to learn concepts, then verify syntax and current behavior against the linked GitHub documentation.
