## Architectural themes

- Choose the action implementation based on runtime requirements, isolation needs, and maintenance cost.
- Treat actions as contracts with explicit inputs, outputs, permissions, and failure behavior.
- Protect supply chain integrity through compatible versioning and pinning practices.
- Validate and operate the action in a test repository before broad adoption.
