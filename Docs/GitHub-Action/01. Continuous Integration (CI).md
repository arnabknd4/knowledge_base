# Continuous Integration (CI)

## 1. What is it?
- Continuous Integration (CI) is a software development practice where developers frequently merge code changes into a shared repository.
- Automated builds and tests run on each integration to detect issues early.

## 2. Why do we need it?
- Ensures code quality and consistency.
- Reduces integration problems by catching bugs early.
- Speeds up delivery cycles and improves collaboration across teams.

## 3. Real World Example
- A team working on a banking app uses GitHub Actions for CI.
- Every time a developer pushes code, automated pipelines run unit tests, security scans, and build validation before merging.

## 4. Exam Perspective
- **Key focus areas:** CI/CD pipeline concepts, tools (Jenkins, GitHub Actions, Azure DevOps, GitLab CI), benefits of automation, and integration with version control.
- Expect questions on differences between CI and CD, pipeline stages, and common CI tools.

## 5. Interview Questions and Answers
- **Q:** What is Continuous Integration?  
  **A:** A practice of merging code frequently into a shared repository with automated builds/tests to ensure stability.  

- **Q:** How is CI different from CD?  
  **A:** CI focuses on integrating and testing code continuously, while CD (Continuous Delivery/Deployment) automates release to production.  

- **Q:** What are common CI tools?  
  **A:** Jenkins, GitHub Actions, GitLab CI, Azure DevOps, CircleCI.

## 6. Common Mistakes
- Not writing enough automated tests.
- Ignoring failed builds and merging broken code.
- Overcomplicating pipelines with unnecessary steps.
- Lack of proper branching strategy.

## 7. Mental Model
Think of CI as a **“safety net”**:
- Developers throw code into the net (repository).
- Automated tests and builds catch errors immediately.
- The net ensures only stable code moves forward.

## 8. Revision Summary
- CI = frequent code merges + automated builds/tests.
- Benefits: faster feedback, fewer bugs, smoother collaboration.
- Tools: Jenkins, GitHub Actions, GitLab CI, Azure DevOps.
- CI is the foundation of modern DevOps pipelines.
