## 1. Learn It (Core Understanding)
- **One-line definition:**  
  Agentic coding workflow is how Claude interacts with the file system and terminal to execute coding tasks.

- **Plain-English explanation (3–4 lines):**  
  Claude agents can read, write, and edit files directly, while also running commands in a terminal.  
  This workflow simulates a developer’s environment, enabling iterative coding, testing, and debugging.  
  It combines file system operations with shell execution for end-to-end automation.

- **Why it exists / problem it solves:**  
  Provides a unified workflow for coding tasks without switching contexts between tools.

- **Key terms to know:**  
  - **File system interaction:** Read, write, edit files.  
  - **Terminal interaction:** Execute commands, scripts.  
  - **Agentic workflow:** Continuous loop of coding + execution.  
  - **Safety checks:** Guardrails for risky commands.

- **How it works (simple steps):**  
  1. Agent reads or edits files.  
  2. Executes commands in terminal.  
  3. Validates results.  
  4. Refines code iteratively.

- **Where it sits in the AI stack:**  
  Execution layer → developer workflow automation.

- **Related topics:** Iterative refinement, CI/CD integration.
