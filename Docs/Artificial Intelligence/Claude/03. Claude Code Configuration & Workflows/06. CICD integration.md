## 1. Learn It (Core Understanding)
- **One-line definition:**  
  CI/CD integration enables Claude to run in pipelines using non‑interactive mode with structured JSON outputs.

- **Plain-English explanation (3–4 lines):**  
  In CI/CD, automation requires predictable, machine-readable outputs.  
  Non‑interactive mode (`-p`) ensures commands run without human prompts.  
  Options like `--output-format json` and `--json-schema` enforce structured outputs for downstream tools.

- **Why it exists / problem it solves:**  
  Prevents manual intervention, ensures reproducibility, and integrates Claude into automated workflows.

- **Key terms to know:**  
  - **Non‑interactive mode (-p):** Runs without user input.  
  - **--output-format json:** Forces JSON output.  
  - **--json-schema:** Validates output against schema.

- **How it works (simple steps):**  
  1. Configure pipeline with Claude commands.  
  2. Use `-p` for non‑interactive execution.  
  3. Enforce JSON output with `--output-format json`.  
  4. Validate structure via `--json-schema`.

- **Where it sits in the AI stack:**  
  Execution → CI/CD automation.

- **Related topics:** Iterative refinement, structured output.
