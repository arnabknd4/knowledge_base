## 1. Learn It (Core Understanding)
- **One-line definition:**  
  Path rules define glob‑scoped conventions for how Claude applies rules to files and directories.

- **Plain-English explanation (3–4 lines):**  
  Glob patterns (`*.md`, `src/**`, etc.) are used to scope rules in CLAUDE.md.  
  They allow selective application of behaviors, restrictions, or workflows to specific file paths.  
  This ensures consistent handling of files across large projects without manual repetition.

- **Why it exists / problem it solves:**  
  Prevents misconfiguration by applying rules only where relevant, reduces noise, and enforces standards.

- **Key terms to know:**  
  - **Glob pattern:** Wildcard syntax for matching paths.  
  - **Scoped convention:** Rule applied only to matching files.  
  - **Inheritance:** Rules cascade unless overridden.

- **How it works (simple steps):**  
  1. Define glob pattern in CLAUDE.md.  
  2. Attach rules (allowed-tools, restrictions).  
  3. Claude applies rules only to matching paths.

- **Where it sits in the AI stack:**  
  Configuration → workflow execution.

- **Related topics:** CLAUDE.md hierarchy, slash commands.

## 3. 🎯 Exam Focus
- **Likely question types:**  
  Definition, scenario (which files match), best-fit.

- **Must-memorize facts:**  
  - `*` matches any characters in a filename.  
  - `**` matches directories recursively.  
  - Rules cascade unless overridden.

- **Keywords that signal this topic in a question:**  
  “glob”, “path rules”, “CLAUDE.md”.

- **Commonly confused with:**  
  Slash commands or CI/CD path filters.

- **Elimination tips:**  
  If question mentions file patterns → path rules.  
  If it mentions `/command` → slash commands.

- **Frameworks / standards link:**  
  Maps to **configuration governance** in ISO 42001.
