## 1. Learn It (Core Understanding)
- **One-line definition:**  
  Plan mode generates a step-by-step execution plan before running, while direct execution runs commands immediately.

- **Plain-English explanation (3–4 lines):**  
  Plan mode is like a “dry run” — the agent outlines what it will do, allowing review and approval.  
  Direct execution skips the planning stage and executes commands right away.  
  Plan mode is safer for complex or high-risk tasks, while direct execution is faster for routine actions.

- **Why it exists / problem it solves:**  
  Balances safety and speed in agent workflows.

- **Key terms to know:**  
  - **Plan mode:** Preview of steps.  
  - **Direct execution:** Immediate action.  
  - **Iterative refinement:** Adjust plan before execution.

- **How it works (simple steps):**  
  1. User triggers command.  
  2. In plan mode → agent outputs plan.  
  3. User reviews/approves → execution.  
  4. In direct execution → agent runs immediately.

- **Where it sits in the AI stack:**  
  Workflow execution layer.

- **Related topics:** Iterative refinement, CI/CD integration.

  Plan mode = safety; direct execution = speed.

- **Compare and contrast:**

  | | Plan Mode | Direct Execution |
  |---|---|---|
  | Purpose | Preview steps | Run immediately |
  | When to use | Complex/high-risk tasks | Routine/simple tasks |
  | Key difference | Requires approval | No approval |
