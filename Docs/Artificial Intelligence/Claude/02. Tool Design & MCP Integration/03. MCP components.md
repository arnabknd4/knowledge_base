## 1. Learn It (Core Understanding)
- **One-line definition:**  
  MCP (Model Context Protocol) defines how agents and applications interact through servers, clients, resources, tools, and prompts.

- **Plain-English explanation (3–4 lines):**  
  The server hosts resources and tools, exposing them via MCP. The client connects to the server, requesting actions or data. Resources are structured data objects, tools are callable functions, and prompts are reusable templates for agent queries. Together, they standardize agent–tool communication.

- **Why it exists / problem it solves:**  
  - Provides interoperability between agents and external systems  
  - Ensures consistent schema and governance  
  - Simplifies tool integration and prompt reuse  

- **Key terms to know:**  
  - **Server:** Hosts MCP resources/tools  
  - **Client:** Connects and consumes MCP services  
  - **Resources:** Data objects exposed via MCP  
  - **Tools:** Functions agents can call  
  - **Prompts:** Pre‑defined query templates  

- **How it works (simple steps):**  
  1. Server defines resources, tools, prompts  
  2. Client connects via MCP protocol  
  3. Agent requests resource or tool execution  
  4. Server responds with structured output  

- **Where it sits in the AI stack:** Integration layer (protocol + orchestration)  
- **Related topics:** [[Tool interface design]], [[SDK hooks]], [[Governance]]
