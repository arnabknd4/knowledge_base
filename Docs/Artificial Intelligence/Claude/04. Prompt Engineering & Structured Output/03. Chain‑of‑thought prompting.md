## 1. Learn It (Core Understanding)
- **One-line definition:**  
  Chain‑of‑thought prompting guides the model to reason step‑by‑step before producing a final answer.

- **Plain-English explanation (3–4 lines):**  
  Instead of jumping straight to an answer, the model is prompted to “think aloud” by writing intermediate reasoning steps.  
  This improves accuracy on complex tasks like math, logic, or multi‑step problem solving.  
  It mirrors human reasoning: breaking problems into smaller steps before concluding.

- **Why it exists / problem it solves:**  
  Reduces hallucinations, improves logical consistency, and makes reasoning transparent.

- **Key terms to know:**  
  - **CoT (Chain‑of‑Thought):** Step‑by‑step reasoning.  
  - **Intermediate steps:** Partial reasoning before final answer.  
  - **Reasoning transparency:** Ability to audit logic.

- **How it works (simple steps):**  
  1. Prompt model with “think step‑by‑step.”  
  2. Model generates reasoning chain.  
  3. Final answer derived from reasoning.  
  4. Optionally validate or retry.

- **Where it sits in the AI stack:**  
  Prompt engineering → reasoning layer.

- **Related topics:** Few‑shot prompting, structured output.

## 3. 🎯 Exam Focus
- **Likely question types:**  
  Definition, scenario (when to use CoT), compare/contrast.

- **Must-memorize facts:**  
  - CoT = step‑by‑step reasoning.  
  - Improves accuracy on complex tasks.  
  - Transparency aids validation.

- **Keywords that signal this topic in a question:**  
  “step‑by‑step,” “reasoning,” “chain‑of‑thought.”

- **Commonly confused with:**  
  Iterative refinement (multi‑pass improvement, not reasoning steps).

- **Elimination tips:**  
  If question mentions “think step‑by‑step” → CoT.  
  If it mentions “retry cycles” → iterative refinement.

## 6. ✅ Dos and ❌ Don'ts

| ✅ Do | ❌ Don't |
|---|---|
| Use CoT for complex tasks | Use CoT for trivial queries |
| Validate reasoning steps | Assume steps are always correct |
| Document reasoning chains | Skip transparency |

- **Common mistakes / misconceptions:**  
  1. Thinking CoT guarantees correctness (it improves but doesn’t ensure).  
  2. Using CoT unnecessarily for simple tasks.

- **Red flags in practice:**  
  No reasoning logs, opaque outputs.
