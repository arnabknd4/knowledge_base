## 1. Learn It (Core Understanding)
- **One-line definition:**  
  Structured output enforces predictable formats (e.g., JSON schemas) and anchors tool use to ensure reliable downstream processing.

- **Plain-English explanation (3–4 lines):**  
  Instead of free‑form text, the model outputs data in structured formats like JSON.  
  Schemas define required fields, types, and constraints, ensuring outputs are machine‑readable.  
  Tool_use anchoring ties outputs directly to tool calls, reducing ambiguity and preventing malformed responses.

- **Why it exists / problem it solves:**  
  Prevents hallucinations, ensures interoperability, and reduces parsing errors in automated workflows.

- **Key terms to know:**  
  - **JSON schema:** Defines structure and validation rules.  
  - **Tool_use anchoring:** Ensures outputs map to tool calls.  
  - **Nullable fields:** Allow flexibility without breaking schema.  
  - **Citation‑required answers:** Enforce provenance.

- **How it works (simple steps):**  
  1. Define schema (fields, types, constraints).  
  2. Prompt model to output strictly in schema format.  
  3. Anchor tool calls to schema fields.  
  4. Validate output before execution.

- **Where it sits in the AI stack:**  
  Prompt engineering → structured governance.

- **Related topics:** Explicit criteria, anti‑fabrication schemas.
