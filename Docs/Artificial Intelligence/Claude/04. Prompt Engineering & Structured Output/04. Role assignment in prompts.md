## 1. Learn It (Core Understanding)
- **One-line definition:**  
  Role assignment in prompts sets the model’s perspective or persona to guide responses.

- **Plain-English explanation (3–4 lines):**  
  By explicitly assigning a role (e.g., “You are a teacher” or “Act as a security auditor”), the model tailors its reasoning and tone.  
  This improves alignment with task requirements and reduces ambiguity.  
  Role assignment is especially useful in structured workflows and exam scenarios.

- **Why it exists / problem it solves:**  
  Prevents generic outputs, enforces context-specific reasoning, and ensures consistency.

- **Key terms to know:**  
  - **Role assignment:** Defining the model’s persona.  
  - **Context anchoring:** Ensuring responses fit the role.  
  - **Persona alignment:** Matching tone and expertise.

- **How it works (simple steps):**  
  1. Define role in prompt (e.g., “You are a lawyer”).  
  2. Provide task instructions.  
  3. Model generates output consistent with role.  
  4. Validate alignment with expected persona.

- **Where it sits in the AI stack:**  
  Prompt engineering → application layer.

- **Related topics:** Few‑shot prompting, structured output.

## 2. Mental Model
- **Analogy:**  
  “Role assignment is like giving an actor a script — the role defines how they perform.”

- **Text Diagram / flow:**  
  Input → [Role assignment: persona] → Task → Output (role-consistent)

- **The one thing to remember:**  
  Role assignment = persona control for context alignment.

- **Compare and contrast:**

  | | Role Assignment | Few‑Shot Prompting |
  |---|---|---|
  | Purpose | Define persona | Provide examples |
  | When to use | Context-specific tasks | Pattern learning |
  | Key difference | Sets identity | Sets behavior via examples |

## 6. ✅ Dos and ❌ Don'ts

| ✅ Do | ❌ Don't |
|---|---|
| Assign clear roles | Leave persona vague |
| Match role to task | Use irrelevant roles |
| Document role usage | Assume role assignment alone ensures accuracy |

- **Common mistakes / misconceptions:**  
  1. Thinking role assignment guarantees correctness.  
  2. Using overly broad or unclear roles.

- **Red flags in practice:**  
  Prompts without role clarity, inconsistent persona outputs.
