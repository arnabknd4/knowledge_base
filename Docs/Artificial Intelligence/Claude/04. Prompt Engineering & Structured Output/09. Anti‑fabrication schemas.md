## 1. Learn It (Core Understanding)
- **One-line definition:**  
  Anti‑fabrication schemas enforce strict rules (nullable fields, citation requirements) to prevent AI from inventing unsupported information.

- **Plain-English explanation (3–4 lines):**  
  These schemas define which fields can be left empty (nullable) and which must include citations.  
  Nullable fields reduce pressure to fabricate when data is missing.  
  Citation‑required answers force the model to provide sources, ensuring provenance and reducing hallucinations.

- **Why it exists / problem it solves:**  
  Prevents fabricated outputs, enforces trustworthiness, and ensures compliance with audit standards.

- **Key terms to know:**  
  - **Nullable fields:** Allow empty values instead of forcing guesses.  
  - **Citation‑required answers:** Demand source attribution.  
  - **Anti‑fabrication schema:** Structured rules to block unsupported claims.

- **How it works (simple steps):**  
  1. Define schema with nullable fields.  
  2. Mark critical fields as citation‑required.  
  3. Validate outputs against schema.  
  4. Reject or retry if citations are missing.

- **Where it sits in the AI stack:**  
  Governance → reliability → compliance.

- **Related topics:** Structured output, validation retry.
