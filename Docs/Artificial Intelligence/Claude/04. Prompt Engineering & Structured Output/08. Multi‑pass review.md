## 1. Learn It (Core Understanding)
- **One-line definition:**  
  Multi‑pass review is the process of evaluating outputs across multiple passes to reduce errors and improve reliability.

- **Plain-English explanation (3–4 lines):**  
  Instead of accepting the first output, the model generates multiple drafts or passes.  
  Each pass is reviewed against criteria, and errors are corrected iteratively.  
  This layered evaluation reduces mistakes and ensures higher‑quality results.

- **Why it exists / problem it solves:**  
  Prevents brittle one‑shot answers, improves accuracy, and enforces quality assurance.

- **Key terms to know:**  
  - **Multi‑pass:** Multiple rounds of evaluation.  
  - **Error reduction:** Catching mistakes across passes.  
  - **Iterative evaluation:** Step‑by‑step review process.  
  - **Feedback loop:** Corrections applied between passes.

- **How it works (simple steps):**  
  1. Generate initial output.  
  2. Review against criteria.  
  3. Generate second pass with corrections.  
  4. Repeat until acceptable quality.  

- **Where it sits in the AI stack:**  
  Prompt engineering → reliability assurance.

- **Related topics:** Validation retry, iterative refinement.
