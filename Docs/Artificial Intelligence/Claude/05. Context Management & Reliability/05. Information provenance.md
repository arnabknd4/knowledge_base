## 1. Learn It (Core Understanding)
- **One-line definition:**  
  Information provenance ensures outputs are traceable to sources, with multi‑source synthesis reducing bias and fabrication.

- **Plain-English explanation (3–4 lines):**  
  Provenance means knowing *where information came from*.  
  Multi‑source synthesis combines insights from diverse sources to create balanced, reliable outputs.  
  Together, they prevent hallucinations, enforce transparency, and support auditability.

- **Why it exists / problem it solves:**  
  Prevents misinformation, enforces accountability, and builds trust in AI outputs.

- **Key terms to know:**  
  - **Provenance:** Traceability of information.  
  - **Multi‑source synthesis:** Combining multiple sources for balanced output.  
  - **Citation enforcement:** Requiring references for claims.  
  - **Bias reduction:** Avoiding reliance on a single source.

- **How it works (simple steps):**  
  1. Collect multiple credible sources.  
  2. Cross‑check consistency.  
  3. Synthesize into unified output.  
  4. Provide citations for provenance.

- **Where it sits in the AI stack:**  
  Governance → trustworthiness → compliance.

- **Related topics:** Anti‑fabrication schemas, confidence scoring.

## 2. Mental Model
- **Analogy:**  
  “Information provenance is like investigative journalism — you don’t trust one witness, you cross‑verify with multiple sources.”

- **Text Diagram / flow:**  
  Sources (A + B + C) → Cross‑check → Synthesized output → Citations

- **The one thing to remember:**  
  Provenance = traceability; synthesis = reliability.

- **Compare and contrast:**

| | Information Provenance | Confidence Scoring |
|---|---|---|
| Purpose | Trace sources | Quantify certainty |
| Trigger | Need for transparency | Probability estimate |
| Human role | Verify citations | Set thresholds |

## 6. ✅ Dos and ❌ Don'ts

| ✅ Do | ❌ Don't |
|---|---|
| Require citations | Allow unsourced claims |
| Use multiple sources | Depend on one source |
