## 1. Learn It (Core Understanding)
- **One-line definition:**  
  Context preservation ensures long conversations remain coherent by using progressive summarization and mitigating lost‑in‑the‑middle effects.

- **Plain-English explanation (3–4 lines):**  
  As conversations grow, models risk forgetting earlier details or over‑focusing on recent inputs.  
  Progressive summarization condenses past context into structured summaries.  
  Lost‑in‑the‑middle effects occur when important details in the middle of a long context window are ignored.  
  Together, these techniques maintain continuity and reduce information loss.

- **Why it exists / problem it solves:**  
  Prevents drift, hallucinations, and incoherence in long prompts or sessions.

- **Key terms to know:**  
  - **Progressive summarization:** Iteratively condensing context while retaining key details.  
  - **Lost‑in‑the‑middle effect:** Model ignores mid‑context information.  
  - **Context window:** Maximum tokens the model can process.  
  - **Anchoring:** Reinforcing critical details across turns.

- **How it works (simple steps):**  
  1. Track conversation history.  
  2. Summarize progressively (retain essentials, drop noise).  
  3. Re‑inject summaries into prompt.  
  4. Guard against lost‑in‑the‑middle by re‑anchoring mid‑context details.

- **Where it sits in the AI stack:**  
  Prompt engineering → memory + context management.

- **Related topics:** Structured output, anti‑fabrication schemas.
