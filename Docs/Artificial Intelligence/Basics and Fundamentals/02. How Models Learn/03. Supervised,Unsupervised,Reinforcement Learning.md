## 1. Learn It (Core Understanding)
- **One-line definition:** The three main ways a machine learning model learns: **supervised** (from labelled examples), **unsupervised** (finding structure in unlabelled data), and **reinforcement** (learning by trial and error from rewards and penalties).
- **Plain-English explanation (3-4 lines):**
  In supervised learning, a teacher provides the right answer for every example, and the model learns to reproduce it. In unsupervised learning, there is no teacher, so the model looks for hidden groups or patterns on its own. In reinforcement learning, an agent acts in an environment, gets a reward or penalty, and gradually learns which actions earn the most reward over time.
- **Why it exists / problem it solves:**
  - Different problems come with different kinds of data and feedback
  - Labelled data is expensive, so methods are needed when labels are scarce or absent
  - Some problems (games, robotics, sequential decisions) have no "right answer" per step, only an outcome that rewards or punishes
- **Key terms to know:**
  - **Supervised learning:** Learns a mapping from inputs (features) to known outputs (labels)
  - **Classification:** Supervised task predicting a category (spam / not spam)
  - **Regression:** Supervised task predicting a number (house price)
  - **Unsupervised learning:** Finds patterns or structure in unlabelled data
  - **Clustering:** Grouping similar items (customer segments)
  - **Dimensionality reduction:** Compressing many features into fewer while keeping key information (PCA)
  - **Anomaly detection:** Spotting unusual items that differ from the norm
  - **Association rules:** Finding items that occur together (market-basket analysis)
  - **Reinforcement learning (RL):** Learning a strategy by interacting with an environment
  - **Agent:** The learner or decision-maker in RL
  - **Environment:** What the agent interacts with
  - **State / Action / Reward:** The situation, the choice made, and the feedback received
  - **Policy:** The agent's strategy for choosing actions
  - **Exploration vs exploitation:** Trying new actions vs repeating what is known to work
  - **Semi-supervised learning:** A small labelled set plus a large unlabelled set
  - **Self-supervised learning:** The model creates its own labels from the data (e.g., predicting the next word); the basis of LLM pre-training
  - **RLHF:** Reinforcement learning from human feedback, used to align LLMs with human preferences
  - **Reward hacking:** The agent exploits a flaw in the reward to score high without doing the intended task
- **How it works (simple steps):**
  1. **Supervised:** Input + correct label → model predicts → compare with label → adjust → repeat → predict labels for new inputs.
  2. **Unsupervised:** Input only → model finds similarities or structure → outputs groups, patterns, or outliers for a human to interpret.
  3. **Reinforcement:** Agent observes state → takes action → environment returns reward and new state → agent updates its policy → repeat to maximise cumulative reward.
- **Where it sits in the AI stack:** Model-training layer. The learning paradigm determines what data you need, how you evaluate, and which risks appear.

## 2. Mental Model
- **Analogy:** Three ways to learn cooking.
  - **Supervised:** a tutor shows you a photo of each dish with its name, and you learn to name new dishes.
  - **Unsupervised:** you are handed a mountain of unlabelled recipes and sort them into groups (desserts, soups, grills) without anyone telling you the categories.
  - **Reinforcement:** you cook without instructions, and diners give you praise or complaints; over many tries you learn what earns applause.
- **Diagram / flow:**
```
  SUPERVISED        Data + LABELS ──► Model ──► Prediction  ◄─ error vs label ─┐
                                        ▲                                      │
                                        └────────── adjust ◄───────────────────┘

  UNSUPERVISED      Data (no labels) ──► Model ──► Clusters / patterns / outliers
                                                   (human interprets)

  REINFORCEMENT     ┌───────► Agent ───action───► Environment ──┐
                    │                                           │
                    └──── reward + new state ◄──────────────────┘
```
- **The one thing to remember:** The difference is the **feedback**: supervised = correct answers, unsupervised = no answers, reinforcement = rewards.
- **Compare and contrast:**

  | | Supervised | Unsupervised | Reinforcement |
  |---|---|---|---|
  | Data | Labelled | Unlabelled | Generated by interaction (states, actions, rewards) |
  | Feedback | Correct answer per example | None | Reward or penalty, often delayed |
  | Goal | Predict labels or values | Discover structure | Maximise cumulative reward |
  | Typical tasks | Classification, regression | Clustering, anomaly detection, dimensionality reduction | Games, robotics, control, sequential decisions |
  | Examples | Spam filter, credit scoring, image classification | Customer segmentation, fraud outlier detection | Game-playing AI, route optimisation, LLM alignment (RLHF) |
  | Evaluation | Accuracy, precision, recall, error | Harder; no ground truth (cluster quality, human review) | Total reward, stability, safety in the environment |
  | Main challenge | Cost and quality of labels | Interpreting results | Reward design, safe exploration, needs many trials |
  | Key risk | Label bias, overfitting | Meaningless or biased clusters | Reward hacking, unsafe actions during learning |

## 3. 🎯 Exam Focus
- **Likely question types:** Definition / Match-the-scenario-to-the-type / Compare / Pick-the-risk
- **Must-memorize facts:**
  - [ ] Supervised = labelled data; tasks are **classification** (category) and **regression** (number)
  - [ ] Unsupervised = unlabelled data; tasks are **clustering, dimensionality reduction, anomaly detection, association**
  - [ ] Reinforcement = agent + environment + **reward**; goal is to maximise cumulative reward
  - [ ] Semi-supervised = few labels + many unlabelled examples
  - [ ] Self-supervised = labels generated from the data itself (LLM pre-training on next-token prediction)
  - [ ] RLHF uses human preference feedback to align LLMs (reinforcement learning applied to language models)
  - [ ] Common supervised algorithms: linear/logistic regression, decision trees, random forests, SVM, neural networks
  - [ ] Common unsupervised algorithms: k-means, hierarchical clustering, PCA, autoencoders
  - [ ] Exploration vs exploitation is a core RL trade-off
  - [ ] Reward hacking and poorly specified rewards are key RL and alignment risks
- **Keywords that signal this topic in a question:**
  - Supervised: "labelled," "target," "predict," "classify," "historical outcomes known"
  - Unsupervised: "unlabelled," "group," "segment," "discover patterns," "outliers"
  - Reinforcement: "agent," "reward," "penalty," "trial and error," "policy," "environment"
- **Commonly confused with:**
  - Classification vs regression (category vs number)
  - Clustering (unsupervised, finds unknown groups) vs classification (supervised, predefined groups)
  - Self-supervised vs unsupervised (self-supervised creates its own labels)
  - Reinforcement learning vs supervised learning (rewards over time vs correct answer per example)
  - RLHF vs ordinary RL (the reward comes from human preferences)
- **Elimination tips (how to rule out wrong options):**
  - First ask: **do we have labels?** Yes → supervised. No → unsupervised. Feedback through rewards from actions → reinforcement.
  - Predicting a **category** → classification; predicting a **number** → regression.
  - "Group customers without predefined categories" → clustering, not classification.
  - Reject "unsupervised learning needs labelled data" and "reinforcement learning needs a labelled dataset."
  - Reject "unsupervised results are automatically correct." With no ground truth, results need human interpretation.
- **Frameworks / standards link:**
  - **EU AI Act:** Does not regulate by learning paradigm. Its data-governance duties for high-risk systems apply to **training, validation, and test data** whichever paradigm is used. Supervised systems depend heavily on labelled-data quality, so label bias is a live concern.
  - **NIST AI RMF:** Risks map to the paradigm: label quality and bias (supervised), validity and interpretability of discovered patterns (unsupervised), and safety, robustness, and unintended behaviour (reinforcement).
  - **ISO/IEC 42001:** Lifecycle and data controls apply regardless of the learning method.
  - **Governance angle:** The paradigm shapes what to audit: label provenance and annotator quality (supervised), cluster validity and human interpretation (unsupervised), reward design and safety constraints (reinforcement).

## 4. 🛠️ Real-World Use Cases
| # | Scenario | Industry | Paradigm and how it applies | Outcome / risk |
|---|---|---|---|---|
| 1 | Loan default prediction from past outcomes | Banking | **Supervised** (classification) | Accurate if data is representative; historical bias may be learned |
| 2 | House or demand price forecasting | Real estate / Retail | **Supervised** (regression) | Good for planning; degrades with market drift |
| 3 | Customer segmentation for marketing | Retail / Telecom | **Unsupervised** (clustering) | Reveals hidden groups; segments may be unstable or unintuitive |
| 4 | Detecting unusual transactions with no fraud labels | Banking / Payments | **Unsupervised** (anomaly detection) | Finds novel fraud; many false positives need human review |
| 5 | Warehouse robot or ad-bidding strategy learning | Logistics / Adtech | **Reinforcement** | Can find strong strategies; unsafe exploration and reward hacking risks |
| 6 | Making an LLM more helpful and safe | AI development | **RLHF** (reinforcement using human feedback) | Better alignment; reflects the preferences and biases of the raters |

- **Consulting / assurance lens:**
  - Ask the client: "What kind of learning does this system use, and where do its labels or rewards come from?"
  - The answer tells you which risks to probe and what evidence to request.
- **Evidence or controls you would look for:**
  - **Supervised:** label sources, annotation guidelines, inter-annotator agreement, bias testing across groups, separate test set results
  - **Unsupervised:** documented rationale for chosen method, validation of clusters or anomalies by domain experts, stability checks, human review of flagged items
  - **Reinforcement:** documented reward function and its intended behaviour, safety constraints, simulation testing before real-world use, monitoring for reward hacking, human override
  - **All:** data lineage, model versioning, monitoring and drift checks

## 5. Q&A Bank

### Quick recall
- **Q:** What is the key difference between supervised and unsupervised learning?
  **A:** Supervised learning uses labelled data with known answers; unsupervised learning uses unlabelled data to find structure.

- **Q:** What are the two main supervised learning tasks?
  **A:** Classification (predict a category) and regression (predict a number).

- **Q:** What does a reinforcement learning agent try to maximise?
  **A:** Cumulative reward over time.

### Conceptual
- **Q:** How does clustering differ from classification?
  **A:** Classification assigns items to predefined categories using labels (supervised). Clustering discovers groups on its own in unlabelled data (unsupervised).

- **Q:** What is self-supervised learning, and why does it matter?
  **A:** The model generates its own training signal from the data (e.g., hiding a word and predicting it). It lets models learn from huge unlabelled datasets, and it is how LLMs are pre-trained.

- **Q:** What is reward hacking?
  **A:** When an agent finds a loophole in the reward function and scores highly without achieving the intended goal. It is why reward design and testing are critical.

- **Q:** What is the exploration vs exploitation trade-off?
  **A:** The agent must balance trying new actions to discover better rewards (exploration) against repeating actions already known to work (exploitation).

### Scenario-based
- **Q:** A retailer wants to group customers by behaviour but has no predefined segments. Which approach fits?
  **A:** Unsupervised learning (clustering), since there are no labels. Results should be validated by business experts.

- **Q:** A bank has ten years of loans with known outcomes (repaid or defaulted) and wants to predict default for new applicants. Which approach fits?
  **A:** Supervised learning (classification). The historical outcomes provide the labels.

- **Q:** A company is training an agent to control a warehouse robot through trial and error in a simulator. Which approach fits, and what is a key risk?
  **A:** Reinforcement learning. Key risks include reward hacking and unsafe behaviour during exploration, so use simulation, safety constraints, and human oversight before real deployment.

- **Q:** A supervised hiring model shows bias against one group. Where would you look first?
  **A:** The training data and labels: historical decisions may embed bias, samples may be unrepresentative, and proxy features may be present. Then test outcomes across groups.

### Interview-style
- **Q:** "Explain the three types of machine learning to a non-technical executive."
  **A:** "Supervised learning is like learning with an answer key: we show the AI thousands of past cases with known outcomes, such as loans that were repaid or defaulted, and it learns to predict new ones. Unsupervised learning is like sorting a pile of items with no labels: the AI finds natural groups, such as customer segments, that we didn't know to look for. Reinforcement learning is learning by trial and error: the AI tries actions, gets rewarded or penalised, and improves, like training a robot or a game-playing system. The type matters for governance because each one has different risks, from biased labels to misinterpreted patterns to unsafe behaviour while learning."

## 6. ✅ Dos and ❌ Don'ts

| ✅ Do | ❌ Don't |
|---|---|
| Choose the paradigm based on whether labels or rewards exist | Force supervised learning when reliable labels don't exist |
| Audit label quality and annotator agreement (supervised) | Assume labels are correct and unbiased |
| Have domain experts validate unsupervised results | Treat clusters or anomalies as facts without review |
| Design and test reward functions carefully (RL) | Deploy an RL agent with an untested or poorly specified reward |
| Use simulation and safety constraints before real-world RL | Let an agent explore freely in live, high-stakes settings |
| Test outcomes across groups for fairness | Assume the paradigm removes bias |
| Document which paradigm, data, and feedback source each model uses | Treat all ML systems as having the same risk profile |

- **Common mistakes / misconceptions:**
  1. "Unsupervised learning needs labels." (It does not.)
  2. "Clustering and classification are the same." (Clustering finds unknown groups; classification uses known ones.)
  3. "Reinforcement learning is just supervised learning with extra steps." (Feedback is a delayed reward, not a correct answer per example.)
  4. "RLHF guarantees a safe model." (It reflects rater preferences and can still be gamed or biased.)
  5. "Unsupervised results are objective." (Interpretation is subjective and needs validation.)
- **Red flags in practice:**
  - No explanation of where labels come from
  - Clusters used for high-stakes decisions without expert validation
  - RL system with an unclear or unvalidated reward function
  - No safety limits on an agent's actions during learning or operation
  - Model type not recorded in the AI inventory

## 7. Revision Snapshot
- **30-second summary:**
  Supervised learning learns from labelled examples to predict categories (classification) or numbers (regression). Unsupervised learning finds structure in unlabelled data (clustering, anomaly detection, dimensionality reduction). Reinforcement learning has an agent learn through rewards and penalties from interacting with an environment. Semi-supervised mixes a few labels with many unlabelled examples; self-supervised generates its own labels, powering LLM pre-training; RLHF uses human feedback to align models. Risks differ: label bias and overfitting (supervised), unreliable interpretation (unsupervised), reward hacking and unsafe exploration (RL).
- **3 bullets to recall on exam day:**
