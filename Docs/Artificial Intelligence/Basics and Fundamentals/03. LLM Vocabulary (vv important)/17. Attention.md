# 🎯 Attention in AI: Types & Categories

## 1. Core Concept
- **Definition:** Attention in AI is a mechanism that allows models to focus on the most relevant parts of input sequences when generating outputs.
- **Purpose:** Improves context handling, captures long‑range dependencies, and enables efficient learning in tasks like translation, summarization, and multimodal reasoning.

---

## 2. Major Categories of Attention

| Category | Description | Example Use |
|----------|-------------|-------------|
| **Additive Attention (Bahdanau)** | Uses feed‑forward layers to compute alignment scores between query and key. | Early neural machine translation. |
| **Multiplicative / Dot‑Product Attention (Luong)** | Computes similarity via dot products; more efficient than additive. | Seq2Seq models. |
| **Scaled Dot‑Product Attention** | Normalizes dot products by √d to stabilize training. | Core of Transformer architecture. |
| **Self‑Attention** | Each token attends to all others in the same sequence. | BERT, GPT models. |
| **Cross‑Attention** | Tokens in one sequence attend to another sequence. | Encoder‑decoder models, multimodal tasks. |
| **Causal / Autoregressive Attention** | Restricts attention to past tokens only. | GPT text generation. |
| **Multi‑Head Attention** | Multiple attention heads capture different relationships simultaneously. | Transformers (GPT‑4, BERT). |

---

## 3. Efficiency‑Oriented Variants
- **Grouped‑Query Attention (GQA):** Groups queries to reduce compute.  
- **Multi‑Query Attention (MQA):** Shares keys/values across heads for efficiency.  
- **Sliding Window Attention:** Restricts focus to local context windows (Longformer, Mistral).  
- **Sparse / Linear Attention:** Approximates full attention with reduced complexity (O(n) vs O(n²)).  
- **FlashAttention:** GPU‑optimized kernel for faster, memory‑efficient attention.

---

## 4. Why Attention Matters
- **Solves RNN bottleneck:** Avoids compressing all input into a single vector.  
- **Improves context handling:** Captures dependencies across long sequences.  
- **Supports multimodal tasks:** Cross‑attention integrates text, image, audio.  
- **Efficiency frontier:** Variants like FlashAttention make long‑context models practical.

---

## 5. Risks & Challenges
- **Quadratic complexity (O(n²)):** Standard attention is costly for long inputs.  
- **Lost‑in‑the‑middle effect:** Models may underweight mid‑context tokens.  
- **Bias amplification:** Skewed attention weights can reinforce bias.

---

## 6. Quick Exam Snapshot
- **Core types:** Additive, multiplicative, self‑attention, cross‑attention, causal, multi‑head.  
- **Efficiency variants:** GQA, MQA, sliding window, sparse/linear, FlashAttention.  
- **Key benefit:** Dynamic focus on relevant tokens.  
- **Main challenge:** Scaling attention efficiently.
