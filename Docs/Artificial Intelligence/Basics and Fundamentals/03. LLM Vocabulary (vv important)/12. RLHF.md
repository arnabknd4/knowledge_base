## 1. Learn It (Core Understanding)
- **One-line definition:** RLHF is a training method that aligns language models with human preferences by using reinforcement learning guided by human feedback.
- **Plain-English explanation (3–4 lines):**  
  After pre-training and fine-tuning, models may still produce unhelpful or unsafe outputs. RLHF improves alignment by collecting human judgments on model responses, training a reward model to predict those judgments, and then using reinforcement learning to adjust the LLM so its outputs better match human expectations of helpfulness, honesty, and safety.
- **Why it exists / problem it solves:**  
  - Makes models more useful and aligned with human values  
  - Reduces toxic, unsafe, or irrelevant outputs  
  - Improves instruction-following and conversational quality  
- **Key terms to know:**  
  - **Reward model:** Predicts human preference scores for outputs  
  - **Policy model:** The LLM being trained to follow preferences  
  - **Reinforcement learning:** Optimisation method using rewards and penalties  
  - **Alignment:** Making AI outputs consistent with human values and expectations  
- **How it works (simple steps):**  
  1. Collect human feedback on model outputs (preferred vs rejected).  
  2. Train a reward model to predict preferences.  
  3. Use reinforcement learning (e.g., PPO) to adjust the LLM with the reward model.  
  4. Deploy aligned model for safer, more helpful use.  
- **Where it sits in the AI stack:** Final alignment stage after pre-training and fine-tuning.

## 2. Mental Model
- **Analogy:** Imagine training a dog. Pre-training teaches it basic behaviours, fine-tuning teaches tricks, and RLHF is like rewarding it with treats when it behaves the way humans want. Over time, it learns to act in ways that please its trainers.  
- **Diagram / flow:**
  - Human feedback → Reward model → Reinforcement learning → Adjusted LLM → Aligned outputs
- **The one thing to remember:** RLHF = aligning models with human preferences using feedback + reinforcement learning.  
- **Compare and contrast:**

| | Fine-tuning | RLHF |
|---|---|---|
| Data | Task/domain-specific | Human preference judgments |
| Objective | Specialisation | Alignment with values |
| Method | Supervised learning | Reinforcement learning with reward model |
| Output | Specialised model | Aligned, safer model |

## 5. Q&A Bank
- **Q:** What is RLHF?  
  **A:** Reinforcement Learning with Human Feedback — aligning models with human preferences using reward models.  

- **Q:** How does RLHF differ from fine-tuning?  
  **A:** Fine-tuning adapts to tasks; RLHF aligns with values and preferences.  

- **Q:** What is a reward model?  
  **A:** A model trained to predict human preference scores for outputs.  

- **Q:** Why is RLHF important?  
  **A:** It reduces unsafe, toxic, or irrelevant outputs and improves alignment.
