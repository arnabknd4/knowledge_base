## 1. Learn It (Core Understanding)
- **One-line definition:** Temperature is a hyperparameter in language models that controls the randomness of token selection during generation.
- **Plain-English explanation (3–4 lines):**  
  When an LLM predicts the next token, it assigns probabilities to possible options. Temperature scales these probabilities: a low temperature makes the model pick the most likely token (deterministic), while a high temperature spreads probability more evenly, allowing more diverse or creative outputs. It’s like adjusting how “adventurous” the model is in its word choice.
- **Why it exists / problem it solves:**  
  - Balances consistency vs creativity in outputs  
  - Allows tuning for different tasks (precise answers vs brainstorming)  
  - Provides control over variability without retraining the model  
- **Key terms to know:**  
  - **Low temperature (≈0–0.3):** Deterministic, repetitive, factual style  
  - **Medium temperature (≈0.7):** Balanced creativity and coherence  
  - **High temperature (>1.0):** Diverse, imaginative, but risk of incoherence  
  - **Sampling:** The process of choosing tokens based on probabilities  
- **How it works (simple steps):**  
  1. Model predicts probabilities for next tokens.  
  2. Apply temperature scaling to adjust distribution.  
  3. Sample token based on adjusted probabilities.  
  4. Repeat until output is complete.  
- **Where it sits in the AI stack:** Inference-time hyperparameter controlling output behaviour.  
- **Related topics:** [[LLM]], [[Generative AI]], [[Sampling]], [[Context Window]]

## 2. Mental Model
- **Analogy:** Imagine rolling a weighted dice. At low temperature, the dice is heavily weighted toward one side (predictable). At high temperature, the dice is more balanced, so many sides can come up (creative but less predictable).  
- **Diagram / flow:**

Probabilities → Apply temperature scaling → Sample token → Append → Repeat

- **The one thing to remember:** Temperature controls randomness: low = consistent, high = creative.  
- **Compare and contrast:**

| | Low Temperature | High Temperature |
|---|---|---|
| Output style | Predictable, factual | Creative, varied |
| Risk | Repetition, blandness | Incoherence, hallucination |
| Best for | Q&A, factual tasks | Brainstorming, creative writing |

## 3. 🎯 Exam Focus
- **Likely question types:** Definition / Scenario (low vs high) / Compare outputs  
- **Must-memorize facts:**  
  - [ ] Temperature scales token probabilities during inference  
  - [ ] Low temperature → deterministic, factual outputs  
  - [ ] High temperature → diverse, creative outputs  
  - [ ] Does not affect training, only inference  
- **Keywords:** "temperature," "randomness," "sampling," "deterministic vs creative"  
- **Commonly confused with:**  
  - Temperature vs model size (temperature controls randomness, not knowledge)  
  - Temperature vs context window (context controls input length, not randomness)  
- **Elimination tips:**  
  - Reject “temperature changes model weights.” It only affects sampling.  
  - Reject “temperature affects training.” It applies at inference.

## 5. Q&A Bank
- **Q:** What does temperature control in an LLM?  
  **A:** The randomness of token selection during inference.  

- **Q:** What happens at low temperature?  
  **A:** The model outputs consistent, predictable text.  

- **Q:** What happens at high temperature?  
  **A:** The model produces diverse, creative text, but may lose coherence.  

- **Q:** Does temperature affect training?  
  **A:** No, it only applies during inference.

## 6. ✅ Dos and ❌ Don’ts
| ✅ Do | ❌ Don’t |
|---|---|
| Use low temperature for factual tasks | Expect high temperature to give reliable facts |
| Use higher temperature for brainstorming | Confuse temperature with model size |
| Adjust temperature per use case | Assume one setting fits all |
| Document chosen temperature in experiments | Ignore variability in outputs |

- **Common mistakes:**  
  1. Thinking temperature changes model knowledge  
  2. Believing temperature affects training  
  3. Assuming higher temperature always improves creativity without risks
