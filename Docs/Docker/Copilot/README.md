## Suggested study sequence

Start with foundations, then learn how to build and distribute images. Continue into runtime operations, networking, storage, and Compose/orchestration. Study security and release engineering throughout rather than treating them as final add-ons. Finish by applying observability, reliability, and role-specific architecture through the portfolio exercises.

For each objective, read its guide, run examples only in a disposable environment, and answer the Q&A from memory. Before production use, verify current Docker documentation, platform behavior, security requirements, and operational ownership.
