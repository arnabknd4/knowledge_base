# Lexical Analysis -
## 1. Core Concept
- Lexical analysis is the first phase of compilation/interpreter execution where source code is broken into tokens.
- Tokens include identifiers (names of variables/functions), literals (fixed values like numbers/strings), and operators (symbols for computation).
- Matters because every script or automation relies on these building blocks for parsing and execution.

## 2. Minimal Snippet
``` py
# Python example
x = 10        # literal
y = 20
sum = x + y   # identifier + operator
print(sum)
```
## 3. Real‑Life Implementation
- **Parsing logs:** extracting identifiers like ERROR, WARN, INFO.
- **Automation scripts:** using operators (&&, ||) to chain commands.
- **Monitoring metrics:** literals define thresholds, identifiers represent metric names.

Example in Bash:
``` sh
threshold=80
cpu_usage=$(top -bn1 | grep "Cpu(s)" | awk '{print $2}')
if [ "$cpu_usage" -gt "$threshold" ]; then
  echo "High CPU usage!"
fi
```
## 4. System Design Angle
- In CI/CD pipelines, identifiers map to environment variables, literals define configs, operators drive conditional logic.
- In distributed systems, lexical tokens are the foundation for DSLs (Domain Specific Languages) like Kubernetes YAML or Terraform HCL.
- Reliability depends on correct tokenization—misused identifiers or operators can break automation.

## 5. Mental Model
- Identifiers = Labels → like naming boxes in a warehouse.
- Literals = Contents → the actual items inside the box.
- Operators = Actions → how boxes interact (add, compare, move).

## 6. Common Pitfalls
- Misnaming identifiers → inconsistent variable names cause confusion.
- Hardcoding literals → reduces flexibility; use configs/env variables instead.
- Operator precedence errors → forgetting parentheses leads to wrong results.

## 7. Architecture Notes
- In microservices, identifiers map to service names, literals define configs, operators drive orchestration logic.
- Example: Kubernetes manifests rely on identifiers (metadata.name), literals (replicas: 3), and operators (==, != in selectors).
- DevOps tooling (Terraform, Ansible) heavily depends on lexical tokens for declarative infra.

## 8. TL;DR Summary
- Identifiers = names, Literals = fixed values, Operators = actions.
- Core tokens in every script and infra automation.
- Misuse leads to brittle pipelines.
- Think of them as labels, contents, and actions.
- One‑liner: Lexical tokens are the DNA of automation scripts.
