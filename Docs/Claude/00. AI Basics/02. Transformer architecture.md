# Transformer Architecture

## 1. What is it?
A deep learning model architecture based on self‑attention mechanisms, designed to process sequences (like text) efficiently and in parallel.

## 2. Why do we need it?
Enables large language models (LLMs) to understand context, capture long‑range dependencies, and scale to massive datasets with high efficiency.

## 3. Core Exam Focus
- **Self‑Attention** → computes relationships between all tokens
- **Multi‑Head Attention** → captures multiple perspectives simultaneously
- **Positional Encoding** → adds sequence order information
- **Feed‑Forward Layers** → transform attention outputs
- **Layer Normalization & Residuals** → stabilize training
- Common trap: forgetting positional encoding → model loses sequence order

## 4. Real‑World Use Case
Claude or GPT‑style LLM:
- Input: enterprise compliance document
- Transformer layers process tokens with self‑attention
- Output: structured summary or JSON extraction
- Scales across billions of parameters for enterprise automation

## 5. Interview Lens
- Q: Why is self‑attention better than RNNs for long sequences?
- Q: How do positional encodings help transformers?
- Q: What trade‑offs exist between multi‑head attention and computational cost?

## 6. Common Mistakes
- Ignoring positional encoding → sequence meaning lost
- Overlooking computational cost → inefficient scaling
- Misunderstanding attention weights → poor interpretability
- Weak regularization → overfitting on small datasets

## 7. Mental Model
Think of transformers as **a panel of experts reading a book**:
- Each expert (attention head) focuses on different relationships
- They compare notes (self‑attention)
- Positional encoding = page numbers to keep order
- Final summary = combined expert insights

## 8. Revision Summary
- Transformer = self‑attention + parallel processing
- Key: multi‑head attention, positional encoding, feed‑forward layers
- Benefits: captures long‑range dependencies, scales efficiently
- Exam traps: missing positional encoding, high compute cost
- Mental model: panel of experts with page numbers
