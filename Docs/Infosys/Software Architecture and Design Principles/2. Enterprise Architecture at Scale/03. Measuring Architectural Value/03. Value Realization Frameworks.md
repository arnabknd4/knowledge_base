# Value Realization Frameworks
## 1. What is it?
- A structured approach to translate architecture activities into measurable business outcomes.  
- Core Infosys concept: EA must deliver tangible value (cost savings, agility, risk reduction, innovation), not just models or standards.

## 2. Why do we need it?
- Bridges the gap between architecture and business strategy.  
- Demonstrates ROI to stakeholders.  
- Provides governance through systematic tracking and reporting.  
- Enables continuous improvement by identifying areas for greater impact.

## 3. Core Exam Focus
- Principles: traceability, measurability, accountability, adaptability.  
- Situational traps: failing to link architecture initiatives to business outcomes.  
- Keywords: TOGAF ADM, Balanced Scorecard, BRM, capability mapping.

## 4. Real‑World Use Case
- Telecom company investing in API‑driven architecture:  
  - Framework → Balanced Scorecard.  
  - KPIs → integration time reduced by 50%, customer satisfaction improved by 15%.  
  - Outcome → faster partner onboarding, improved customer experience.

## 5. Interview Lens
- Q: How would you apply TOGAF for value realization?  
  A: Use ADM to trace requirements → architecture → implementation → benefits, ensuring governance and stakeholder alignment.  
- Q: Why is Balanced Scorecard useful for EA?  
  A: It provides a holistic view across financial, customer, internal process, and innovation perspectives.

## 6. Common Mistakes
- Treating EA deliverables as technical outputs without business linkage.  
- Ignoring KPIs or failing to measure benefits post‑implementation.  
- Lack of accountability for value delivery.  
- Using frameworks rigidly without adapting to business context.

## 7. Mental Model
- Analogy: **“Architecture Value Chain”** — frameworks ensure every link (initiative → capability → KPI → outcome) is traceable.  
- Mnemonic: **“TBBC → TOGAF, Balanced Scorecard, BRM, Capability Mapping.”**

## 8. Revision Summary
- Value realization = architecture tied to measurable business outcomes.  
- Principles → traceability, measurability, accountability, adaptability.  
- Frameworks → TOGAF ADM, Balanced Scorecard, BRM, Capability‑Based Value Mapping.  
- Example → telecom API adoption with measurable KPIs.  
- Exam trap → ignoring measurement, treating EA as technical only.
