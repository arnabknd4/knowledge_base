# Prioritization Frameworks
## 1. What is it?
- Structured methods to decide which initiatives should be executed first when creating a roadmap.  
- Core Infosys concept: prioritization ensures limited resources deliver maximum business impact.

## 2. Why do we need it?
- Organizations cannot start all initiatives at once due to constraints (time, budget, talent).  
- Frameworks provide transparency, stakeholder alignment, and focus on high‑value outcomes.  
- Prevents wasted effort on low‑impact projects.

## 3. Core Exam Focus
- Principles: prioritization, resource optimization, stakeholder alignment.  
- Situational traps: treating all initiatives equally or ignoring business value vs. effort.  
- Keywords: MoSCoW, Value vs. Effort, Weighted Scoring, Kano.

## 4. Real‑World Use Case
- Infosys digital transformation roadmap:  
  - Must‑have → Cloud migration.  
  - Should‑have → Microservices adoption.  
  - Could‑have → AI personalization.  
  - Won’t‑have → Blockchain integration (for now).  
- Value vs. Effort matrix → API integration identified as quick win.  
- Weighted scoring → Cloud migration scored highest due to ROI and alignment.

## 5. Interview Lens
- Q: How would you apply Value vs. Effort in prioritization?  
  A: Plot initiatives on a 2x2 matrix, select quick wins first, plan strategic bets carefully.  
- Q: Why is Weighted Scoring more reliable than MoSCoW?  
  A: It removes subjectivity by quantifying alignment, ROI, risk, and complexity.

## 6. Common Mistakes
- Overloading “Must‑have” category in MoSCoW.  
- Ignoring effort dimension in Value vs. Effort matrix.  
- Assigning arbitrary weights in scoring models.  
- Using Kano model without validating customer satisfaction data.

## 7. Mental Model
- Analogy: **“Resource Filter”** — frameworks act like filters to separate high‑impact initiatives from noise.  
- Mnemonic: **“MVWK → MoSCoW, Value/Effort, Weighted, Kano.”**

## 8. Revision Summary
- Prioritization = focus resources on high‑impact initiatives.  
- MoSCoW → Must, Should, Could, Won’t.  
- Value vs. Effort → Quick wins vs. strategic bets.  
- Weighted Scoring → Quantitative, removes subjectivity.  
- Kano → Customer satisfaction lens.  
- Exam trap: treating prioritization as subjective or ignoring effort/value balance.
