# Master Git Revision Sheet

---

# Basic Snapshotting
- **add** → Marks changes for the next snapshot; moves files from working area to staging.  
- **status** → A mirror showing what’s staged, modified, or clean before committing.  
- **diff** → The magnifying glass for change; compares current edits against last snapshot.  
- **commit** → Captures a full snapshot of staged changes; freezes your project’s state in history.  
- **notes** → Sticky annotations attached to commits; metadata without altering history.  
- **restore** → Time rewind for files; brings them back from a previous snapshot or discards edits.  
- **reset** → Moves the branch pointer backward; erases or unstages commits depending on mode.  
- **rm** → Removes tracked files from both working directory and index; cleans up the snapshot.  
- **mv** → Renames or moves files while preserving history; updates the tree structure.  

---

# Branching and Merging
- **branch** → A movable pointer to a commit; think of it as a “timeline label” for your work.  
- **checkout** → Time travel to a specific commit or branch; swaps your working directory snapshot.  
- **switch** → A safer, modern way to change branches without touching detached commits.  
- **merge** → Combines two timelines into one; integrates parallel histories.  
- **mergetool** → Visual conflict resolver; lets you see and fix overlapping changes.  
- **log** → The project’s time machine; shows the evolution of commits and branches.  
- **stash** → A temporary shelf for unfinished work; hides changes without committing.  
- **tag** → A permanent bookmark on a commit; marks milestones like releases.  
- **worktree** → A parallel workspace linked to the same repo; multiple branches, one source.  

---

# Sharing and Updating Projects
- **fetch** → Downloads new commits from remote; updates your local knowledge without touching your working files.  
- **pull** → Fetch + merge/rebase; brings remote changes directly into your current branch snapshot.  
- **push** → Uploads your local commits to the remote; shares your timeline with others.  
- **remote** → A named pointer to another repository; think of it as a “shortcut address” for collaboration.  
- **submodule** → A repository inside another repo; nested timelines for shared dependencies.  

---

# Inspection and Comparison
- **show** → A spotlight on a specific commit or object; reveals details instantly.  
- **log** → The project’s timeline diary; lists commits as a narrative of history.  
- **diff** → The magnifying glass for change; compares edits between snapshots.  
- **difftool** → A visual lens for differences; external viewer to inspect changes side‑by‑side.  
- **range-diff** → A comparative microscope; shows differences between two commit ranges.  
- **shortlog** → A summarized leaderboard; groups commits by author or message for quick review.  
- **describe** → A human‑friendly label; names a commit based on the nearest tag.  

---

# Patching
- **apply** → Installs a patch file onto your repo; think of it as “pasting changes” from elsewhere.  
- **cherry-pick** → Plucks a single commit from another branch; grafts it onto your current timeline.  
- **diff** → The microscope for change; shows what a patch would alter compared to the snapshot.  
- **rebase** → Rewrites history by replaying commits onto a new base; aligns timelines cleanly.  
- **revert** → Creates an “undo commit”; cancels changes by adding a new opposite snapshot.  

---

# Debugging
- **bisect** → A detective’s binary search; narrows down which commit introduced a bug.  
- **blame** → A spotlight on each line; shows who last changed it and when.  
- **grep** → The search engine inside Git; hunts through tracked content for patterns.  

---

# Administration
- **clean** → Sweeps away untracked files; tidies your working directory like a broom.  
- **gc** → Garbage collector; compresses and prunes unused objects to keep the repo lean.  
- **fsck** → Health check doctor; verifies integrity of Git objects and detects corruption.  
- **reflog** → The secret diary of branch pointers; lets you recover “lost” commits.  
- **filter-branch** → History surgeon; rewrites commits across a branch (e.g., remove secrets).  
- **instaweb** → Instant web server; spins up a quick browser view of your repo.  
- **archive** → Creates a snapshot package; bundles files into a tar/zip without Git metadata.  
- **bundle** → A portable repo suitcase; packs commits into a single file for transfer.  

---

# Server Admin
- **daemon** → Git’s “radio tower”; lightweight server broadcasting repos.  
- **update-server-info** → Git’s “index refresh”; prepares repo for HTTP serving.  

---

# Plumbing Commands
- **cat-file** → Git’s “X-ray machine”; inspect object internals.  
- **check-ignore** → Rule checker for ignored files.  
- **checkout-index** → Staging area exporter.  
- **commit-tree** → Manual snapshot builder.  
- **count-objects** → Weighing scale for Git objects.  
- **diff-index** → Before vs. after lens.  
- **for-each-ref** → Loop over branches/tags.  
- **hash-object** → Fingerprint generator for content.  
- **ls-files** → Catalog of staged files.  
- **ls-tree** → Folder viewer for commits.  
- **merge-base** → Family tree root finder.  
- **read-tree** → Loader for snapshots into index.  
- **rev-list** → Commit enumerator.  
- **rev-parse** → Translator from names to IDs.  
- **show-ref** → Directory of references.  
- **symbolic-ref** → Signpost editor for refs.  
- **update-index** → Manual stager.  
- **update-ref** → Pointer mover.  
- **verify-pack** → Packfile inspector.  
- **write-tree** → Snapshot writer for index.

# Revision Summary (One‑Pager)

- **Snapshotting** → `add` (stage), `status` (check), `diff` (compare), `commit` (snapshot), `restore/reset` (rewind), `rm/mv` (remove/move).  
- **Branching & Merging** → `branch` (label timeline), `checkout/switch` (move between timelines), `merge` (combine), `stash` (shelf work), `tag` (bookmark), `worktree` (parallel workspace).  
- **Sharing & Updating** → `fetch` (download only), `pull` (fetch+merge), `push` (upload), `remote` (repo shortcut), `submodule` (nested repo).  
- **Inspection & Comparison** → `show` (spotlight commit), `log` (timeline diary), `diff/difftool` (change lens), `range-diff` (compare ranges), `shortlog` (summary), `describe` (nearest tag label).  
- **Patching** → `apply` (paste patch), `cherry-pick` (pluck commit), `rebase` (replay history), `revert` (undo commit).  
- **Debugging** → `bisect` (binary search bug), `blame` (who changed line), `grep` (search content).  
- **Administration** → `clean` (sweep untracked), `gc` (garbage collect), `fsck` (health check), `reflog` (recover lost commits), `filter-branch` (rewrite history), `archive/bundle` (package repo).  
- **Server Admin** → `daemon` (lightweight Git server), `update-server-info` (prep for HTTP serving).  
- **Plumbing** → `cat-file` (inspect object), `hash-object` (fingerprint content), `ls-files/ls-tree` (list index/tree), `rev-list` (list commits), `rev-parse` (resolve refs), `merge-base` (find ancestor), `update-index/ref` (manual staging/pointers), `verify-pack` (check packfile), `write-tree` (save index snapshot).
