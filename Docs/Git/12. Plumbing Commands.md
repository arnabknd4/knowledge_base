# Plumbing Commands

## cat-file
- **What is it?**  
  Displays contents or type of Git objects.  
- **Why do we need it?**  
  To inspect raw internals (commits, trees, blobs).  
- **Mental Model**  
  Think of it as Git’s “X-ray machine” for objects.  
- **Revision summary**  
  `git cat-file` = inspect object internals.  

---

## check-ignore
- **What is it?**  
  Shows which ignore rules apply to a file.  
- **Why do we need it?**  
  Debug `.gitignore` behavior.  
- **Mental Model**  
  A “rule checker” for ignored files.  
- **Revision summary**  
  `git check-ignore` = verify ignore rules.  

---

## checkout-index
- **What is it?**  
  Copies files from index to working directory.  
- **Why do we need it?**  
  Restore staged versions of files.  
- **Mental Model**  
  A “staging area exporter.”  
- **Revision summary**  
  `git checkout-index` = pull staged files out.  

---

## commit-tree
