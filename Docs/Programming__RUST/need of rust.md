# Why Should I Learn Rust?

As a **40-year-old .NET Technical Lead** aiming to transition into **Cloud Architect, Platform Engineering, or SRE roles**, Rust is one of the few languages that can genuinely expand your technical depth rather than simply adding another programming language to your résumé.

## Why Rust Is Worth Learning

### 1. Rust Teaches Systems Thinking

As a .NET developer, you're accustomed to:

- Garbage collection
- Managed memory
- Runtime safety

Rust forces you to understand:

- Memory ownership
- Lifetimes
- Resource management
- Concurrency
- Performance trade-offs

Even if you never become a full-time Rust developer, these concepts will make you a stronger architect and engineer.

---

### 2. Cloud Infrastructure Is Increasingly Using Rust

Many modern cloud and infrastructure projects choose Rust because it combines:

- C/C++-level performance
- Memory safety
- Strong concurrency guarantees

Examples include:

- AWS Firecracker
- Deno
- TiKV
- Vector
- Ruff
- Various Linux ecosystem tools

As Platform Engineering and SRE continue to grow, Rust-based tools are becoming increasingly common.

---

### 3. Rust Is Excellent for High-Performance Services

In .NET, performance-critical workloads often require careful optimisation or native integrations.

Rust enables you to build:

- High-throughput APIs
- Networking services
- Streaming systems
- Message-processing applications

with:

- Low latency
- Low memory consumption
- Predictable performance

This becomes particularly valuable when cloud costs matter.

---

### 4. Safer Concurrency

Rust's compiler prevents many common runtime bugs before code is ever executed.

Examples include:

- Data races
- Null pointer issues
- Thread-safety mistakes
- Use-after-free errors

For distributed systems and platform workloads, this is a major advantage.

---

### 5. Strong Fit for Platform Engineering and SRE

Rust is particularly well suited for building:

- CLI tools
- Kubernetes operators
- Monitoring agents
- Service mesh components
- Infrastructure automation tools

These are exactly the types of systems Platform Engineers and SREs often develop and maintain.

---

### 6. It Differentiates You

There are many .NET developers in the market.

There are significantly fewer professionals who combine:

- .NET expertise
- Technical leadership experience
- Cloud knowledge
- Rust skills

That combination is uncommon and can help you stand out.

---

## Reasons NOT to Learn Rust

Be practical about the trade-offs.

### If Your Goal Is Cloud Architect

The following skills will usually provide a higher immediate return on investment:

1. Azure Architecture
2. Kubernetes
3. Terraform/OpenTofu
4. Platform Engineering
5. Security
6. Observability

These skills appear much more frequently in Cloud Architect job descriptions than Rust.

---

### Rust Has a Steep Learning Curve

Rust is one of the most challenging modern mainstream languages.

Common challenges include:

- Ownership
- Borrowing
- Lifetimes
- Advanced type system concepts

Expect several weeks before the language truly starts to feel natural.

---

## My Recommendation for Your Career

If I were advising someone with your profile, I would prioritise learning in this order:

1. Azure Architecture
2. Kubernetes
3. Terraform/OpenTofu
4. Platform Engineering Principles
5. Observability (OpenTelemetry, Prometheus, Grafana)
6. Rust

### Why Rust Is #6

The first five areas directly increase your readiness for:

- Cloud Architect roles
- Platform Engineer roles
- SRE positions

Rust then becomes a powerful differentiator that deepens your engineering expertise.

---

## Practical Rust Learning Path

Rather than learning Rust through isolated exercises, build projects aligned with your career goals.

### Project 1: Command-Line Tool

Learn:

- Ownership
- Error handling
- File operations

### Project 2: Log Parser

Learn:

- Data processing
- Performance optimisation
- Iterators

### Project 3: REST API (Axum)

Learn:

- Async programming
- Web services
- Concurrency

### Project 4: Kubernetes Utility

Learn:

- Kubernetes APIs
- Cloud-native development

### Project 5: Infrastructure Automation Tool

Learn:

- Platform engineering concepts
- Automation workflows

### Project 6: Observability Agent

Learn:

- Metrics collection
- Logging
- Distributed systems concepts

---

# Final Verdict

**Learn Rust if:**

- You enjoy understanding how systems work internally.
- You want stronger engineering fundamentals.
- You're interested in Platform Engineering or SRE.
- You enjoy building tools and infrastructure.

**Prioritise cloud and platform skills first if:**

- Your primary goal is becoming a Cloud Architect.
- You want the fastest path to higher-paying cloud-focused roles.

For your career trajectory, Rust is a **high-value multiplier**, but Kubernetes, Terraform, cloud architecture, and observability will likely deliver a faster return on investment in the short term.
