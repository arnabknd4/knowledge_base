# GitHub Actions Billing and Usage

## 1. What is it?
- GitHub Actions billing is based on **minutes consumed by workflows** and **storage used by artifacts and logs**.
- Usage is tracked per **repository, organization, and account**.
- Different plans (Free, Pro, Team, Enterprise) have varying included minutes and storage.

## 2. Why do we need it?
- To **control CI/CD costs** and avoid exceeding plan limits.
- Provides visibility into **workflow efficiency** and **resource consumption**.
- Helps organizations plan budgets and optimize pipelines.

## 3. Real World Example
- **Minutes Consumption**:
  - GitHub-hosted runners → billed per minute (Linux cheaper, Windows/macOS higher).
  - Self-hosted runners → no minute cost, but infrastructure cost applies.
- **Storage**:
  - Artifacts and logs stored in GitHub → billed per GB/month beyond free quota.

## 4. Exam Perspective
- Know difference between **GitHub-hosted vs self-hosted runners** billing.
- Understand **included minutes/storage per plan**.
- Be able to explain how to view usage metrics in **Insights → Actions Usage**.
- Expect scenario questions on optimizing workflows to reduce billing.

## 5. Interview Questions and Answers
- **Q:** How is GitHub Actions billed?  
  **A:** Based on workflow minutes (runner type dependent) and artifact/log storage.  

- **Q:** Difference between GitHub-hosted and self-hosted runners in billing?  
  **A:** GitHub-hosted runners consume billed minutes; self-hosted runners don’t, but you pay for infrastructure.  

- **Q:** How can you reduce GitHub Actions costs?  
  **A:** Optimize workflows, cache dependencies, use self-hosted runners, and clean up artifacts.

## 6. Common Mistakes
- Assuming self-hosted runners are “free” (infra costs still apply).  
- Forgetting artifact cleanup → storage costs accumulate.  
- Ignoring OS differences → macOS runners are more expensive.  
- Not monitoring usage → unexpected billing spikes.

## 7. Mental Model
Think of GitHub Actions billing as **“utility billing for CI/CD”**:
- Minutes = electricity consumed.  
- Storage = disk space rented.  
- Plan quota = free allowance before charges apply.

## 8. Revision Summary
- Billing = workflow minutes + artifact/log storage.  
- GitHub-hosted runners billed per minute (Linux cheapest, macOS most expensive).  
- Self-hosted runners avoid minute billing but incur infra costs.  
- Usage metrics available in **Insights → Actions Usage**.  
- Optimize workflows to reduce costs.
