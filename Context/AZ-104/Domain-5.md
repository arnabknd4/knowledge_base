
### 5. Monitor & Maintain Azure Resources
- Monitoring & Alerts
    -Configure Azure Monitor metrics and diagnostic settings
    - Create and manage alerts (metric, log, activity log)
    - Use Log Analytics queries and Workbooks
- Backup & Recovery
    - Configure Azure Backup for VMs and workloads
    - Implement recovery services vaults
- Automation
    - Use Azure Automation accounts and runbooks
    - Implement Logic Apps for task automation

#### Service wise breakdown-
- Azure Monitor → Metrics, diagnostic settings, activity logs
- Log Analytics → Queries, workbooks, dashboards
- Alerts → Metric alerts, log alerts, action groups
- Backup & Recovery → Recovery Services vaults, VM backup, restore
- Automation → Runbooks, Update Management, Logic Apps
