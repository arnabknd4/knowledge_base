## Training Plan

## AZ-104 Exam

### 1. Manage Azure Identities & Governance
- Microsoft Entra ID (Azure AD)
    - Create/manage users, groups, and licenses
    - Manage external users (B2B collaboration)
    - Configure self‑service password reset (SSPR)
- Role‑Based Access Control (RBAC)
    - Assign built‑in roles at different scopes (subscription, resource group, resource)
    - Create and manage custom roles
    - Interpret access assignments

- Governance Tools
    - Implement Azure Policy (built‑in and custom)
    - Configure resource locks and tags
    - Manage resource groups and subscriptions
    - Configure management groups for hierarchy

#### Service wise breakdown-
- **Microsoft Entra ID (Azure AD)** → Users, groups, licenses, conditional access, MFA
- **Role‑Based Access Control (RBAC)** → Built‑in/custom roles, scopes, access reviews
- **Azure Policy** → Built‑in/custom policies, initiatives, compliance
- **Resource Governance?** → Resource groups, management groups, subscriptions, tags, locks
