
### 3. Deploy & Manage Compute Resources
- Virtual Machines (VMs)
    - Create/configure VMs (sizes, disks, extensions, encryption)
    - Configure availability zones and availability sets
    - Move VMs across resource groups/subscriptions
- VM Scale Sets
    - Deploy and configure scale sets
    - Autoscaling rules and load balancing integration
- Automation & Templates
    - Deploy resources using ARM templates and Bicep
    - Configure VM images and custom scripts
- Other Compute Services
    - Manage Azure App Services basics (deployment slots, scaling)
    - Configure container instances

#### Service wise breakdown-

- Virtual Machines (VMs) → Sizes, disks, extensions, availability sets/zones, encryption
- VM Scale Sets → Autoscaling, load balancing integration
- Azure App Services → Web apps, deployment slots, scaling basics
- Azure Container Instances (ACI) → Lightweight container deployment
- Automation → ARM templates, Bicep, custom images, cloud‑init
