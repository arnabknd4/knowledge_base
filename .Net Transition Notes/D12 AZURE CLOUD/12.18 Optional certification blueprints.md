1 What is it
- This topic is a menu of five optional certifications. You choose from it only when a target job asks for one.
- AZ-500 is the Azure security engineer exam. Terraform Associate tests infrastructure as code (IaC), meaning infrastructure described in files. GH-200 covers GitHub Actions, GitHub's pipeline tool. CKA and CKAD are Kubernetes exams. AI-200 is an AI-related exam; I cannot confirm its exact scope (verify).
- Legacy equivalent: like the optional Microsoft MCSD add-on exams of the .NET Framework era, taken only when a role needed them.

4 Features and core concepts
- AZ-500: proves you can secure Azure workloads. Outline areas are identity and access, networking, compute/storage/databases, and security operations (verify current outline). It matters for security-heavy architect roles.
- Terraform Associate: proves you know Terraform basics, such as state, providers, modules, and the plan and apply cycle. Check the current exam version on the HashiCorp page (verify). It matters because many Azure job posts list Terraform.
- GH-200: proves you can build GitHub Actions workflows. Check whether the exam is still offered (verify status). It matters mainly if your target company uses GitHub, since you already know GitLab CI.
- CKA (Certified Kubernetes Administrator): a hands-on exam on running clusters. It is done in a live terminal, not multiple choice (verify format). It matters for platform and AKS roles.
- CKAD (Certified Kubernetes Application Developer): the same hands-on style, but for deploying apps on Kubernetes. It matters if you build services rather than run clusters.
- AI-200: scope and status unclear (verify). Check Microsoft Learn before planning any study time.
- Common thread: all are optional proof, not skills. Hands-on labs matter more than the paper.

6 Real-world use case
- Situation: a Kolkata job posting for a cloud architect lists Terraform and AKS. You hold AZ-104 and AZ-400 from earlier phases.
- Choice: take Terraform Associate, because it is cheap, short, and matches your Terraform topic 7.07 and capstone work.
- Trade-off: CKA gives deeper Kubernetes credibility but costs far more preparation time.
- When NOT to use it: do not chase these before Phase 1 and AZ-104 are done. A certificate without project proof does not impress interviewers.
