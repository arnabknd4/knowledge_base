1 What is it
- AZ-400 is the Microsoft exam for the Azure DevOps Engineer Expert certification. It tests how you design and run DevOps: source control, pipelines, security, and monitoring.
- This topic is the exam blueprint (the official list of skills and weights) plus a plan for passing it.
- Legacy equivalent: your GitLab CI and release work, measured against Microsoft's Azure DevOps and GitHub vocabulary.

2 Why needed
- The exam rewards design choices and the Microsoft way of naming things, not only hands-on skill.
- Without the blueprint you study what you already know and miss the weighted areas.
- The certification gives proof of cloud DevOps skill for lead and architect job filters.

4 Features and core concepts
- Skills outline: the official Microsoft Learn page listing every measured skill and its percentage weight. It tells you what to study and how long to spend on each part. Always read the current version (verify).
- Domain 1, processes and communications (about 10 to 15 percent, verify): work tracking, flow metrics, dashboards, collaboration, documentation. Small weight, easy marks.
- Domain 2, source control strategy (about 10 to 15 percent, verify): branching models, pull request policies, repository structure, large files and cleanup. Your Git knowledge helps here.
- Domain 3, build and release pipelines (about 50 to 55 percent, verify): agents and pools, YAML pipelines, templates, packages, testing, deployment strategies, infrastructure as code. This is the largest block, so study it most.
- Domain 4, security and compliance plan (about 10 to 15 percent, verify): secrets, service connections, scanning, Key Vault, dependency and code checks. Matters because DevSecOps is asked in every case study.
- Domain 5, instrumentation strategy (about 5 to 10 percent, verify): Azure Monitor, Application Insights, alerts, KQL basics, feedback loops.
- Prerequisite rule: the Expert certificate is awarded only if you also hold Azure Administrator Associate (AZ-104) or Azure Developer Associate (AZ-204) (verify). This is why AZ-104 comes first in your plan.
- Question styles: multiple choice, drag and drop, case studies, and sometimes lab-style tasks (verify). Practice assessments on Microsoft Learn show the styles.
- Renewal: a free online assessment on Microsoft Learn, taken before the certificate expires, renews it each year.

5 Core focus (exam and interview)
- Pipelines carry about half of the marks. Know YAML structure: stages, jobs, steps, templates, variable groups, environments, approvals.
- Know service connections, workload identity federation, and Key Vault in pipelines.
- Expect scenario questions: choose the right deployment strategy, branching policy, or scanning tool.
- Know both Azure DevOps and GitHub Actions answers. Questions often offer both.
- Passing score is 700 out of 1000. Check the current exam length, question count and price on the exam page (verify).

6 Real-world use case
- Situation: a client moves from GitLab CI to Azure DevOps and asks for an audit-ready pipeline.
- Choice: YAML templates for build and test, environments with approvals for production, Key Vault for secrets, OIDC instead of stored credentials, Application Insights alerts after release.
- Trade-off: strong control and audit trail, but more setup and a learning curve for the team.
- When not to use it: small teams with no compliance need can stay on simple pipelines without approval gates.

7 Interview lens
- Q: Which domain is largest on AZ-400? A: Build and release pipelines, about half the exam (verify). Study there first.
- Q: How do you avoid stored secrets in a pipeline? A: Use workload identity federation and Key Vault references. No password sits in the repository or variables.
- Q: Why does the exam need AZ-104 or AZ-204? A: It is a prerequisite for the Expert certificate (verify). Without it, you pass the exam but get no certificate.
- Q: How do you renew? A: Take the free renewal assessment on Microsoft Learn before expiry.

8 Common mistakes
- Studying only Azure DevOps and ignoring GitHub Actions. Questions then look unfamiliar. Fix: map every concept to both tools.
- Using an old blueprint from a blog. Weights and skills change. Fix: read the Microsoft Learn skills outline first.
- Skipping practice assessments. You meet the question style on exam day. Fix: take at least two before booking.
- Only reading, no hands-on. Lab-style questions fail you. Fix: run each domain once in a free organization.

9 Mental model
- Blueprint is a map with weights.
- Half the map is pipelines, the other half is five small areas that need a quick pass.
- Study order: weights, then weak spots, then practice test, then exam.

10 Mini lab (about 35 minutes)
- Open the current AZ-400 skills outline on Microsoft Learn. Copy the five domains and weights into a page. Compare with this note and fix anything that changed.
- Take the free AZ-400 practice assessment on Microsoft Learn. Write your score per domain.
- Create a free Azure DevOps organization. Push a small .NET app and add a YAML pipeline with restore, build and test steps.
- Add an environment named prod with a manual approval check. Run the pipeline and approve it once.
- Expected result: pipeline passes, and the prod stage waits for your approval.
- Clean-up: delete the pipeline, environment and project. Keep the weak-domain list as your study plan.
