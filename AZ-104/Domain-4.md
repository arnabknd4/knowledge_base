
### 4. Implement & Manage Virtual Networking
- Virtual Networks (VNets)
    - Create/configure VNets and subnets
    - Configure VNet peering (same/different regions)
- Network Security
    - Configure Network Security Groups (NSGs) and Application Security Groups (ASGs)
    - Evaluate effective security rules
- Routing & Connectivity
    - Configure user‑defined routes
    - Manage public IPs and DNS settings
    - Troubleshoot connectivity issues
- Hybrid Connectivity
    - Configure VPN Gateway basics
    - ExpressRoute overview

#### Service wise breakdown-
- Virtual Networks (VNets) → Subnets, peering, DNS, service endpoints
- Network Security → NSGs, ASGs, effective rules evaluation
- Routing → User‑defined routes, public IPs, private endpoints
- Hybrid Connectivity → VPN Gateway, ExpressRoute basics
- Load Balancing → Azure Load Balancer, Application Gateway
