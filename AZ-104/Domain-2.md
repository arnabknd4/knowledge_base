
### 2. Implement & Manage Storage
- Storage Accounts
    - Create/configure storage accounts (types, redundancy: LRS, ZRS, GRS, RA‑GRS)
    - Configure firewalls and VNet rules
- Access & Security
    - Manage access keys
    - Configure Shared Access Signatures (SAS) and stored access policies
        - Identity‑based access for Azure Files
- Data Management
    - Configure blob lifecycle management
    - Object replication across regions
    - Storage account encryption (Microsoft‑managed vs customer‑managed keys)
- Tools
    - Use AzCopy and Storage Explorer for data transfer

#### Service wise breakdown-

- **Storage Accounts** → Types (General v2, Blob, File), redundancy (LRS/ZRS/GRS/RA‑GRS)
- **Blob Storage** → Containers, blob tiers (hot/cool/archive), lifecycle management
- **Azure Files** → SMB/NFS shares, identity‑based access, sync with on‑premises
- **Data Security** → SAS tokens, access keys, encryption (Microsoft vs customer‑managed keys)
- **Tools** → AzCopy, Storage Explorer, REST API
